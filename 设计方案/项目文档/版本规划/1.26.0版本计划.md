## 二、范围与排除项

### 2.1 A 类：数值

纳入：

- 各系列工具/武器的耐久、攻击伤害和攻击速度；玩家装备护甲各部位的防御值与耐久。
- 怪物的最大生命、攻击力和护甲值，包含四种虚卒以及普通与命途配置的遗迹监守者。
- 共享命途等级加成、九命途等级差异加成、九命途行迹属性节点与被动加成。

不纳入动物数值、玩家基础属性、独立韧性/破韧系统、工具采掘等级/挖掘速度/附魔值、护甲韧性与击退抗性（除作为命途/行迹加成列出的属性外）、怪物招式时序/范围/生成条件/掉落奖励、遗迹挑战奖励/流程阈值、食物饱食属性、配方、方块硬度、群系/维度/世界生成以及其他系统参数。命途等级和行迹中明确给出的护甲或护甲韧性成长仍纳入，因为它们属于命途加成；不因此扩展到独立韧性/破韧系统。光锥与遗器装备数值排除。

排除通票、徽记、命途试炼凭证、动物蛋以及其他普通物品、方块和植物图标。食物数值、配方和植物/方块机制不纳入 A 类。

## 三、统计口径与源码优先级

- 当前源码、当前注册和模型引用是现状依据；历史计划和旧提案不能覆盖当前源码值。本文件的数值是 2026-10-30 源码快照，实施前须复核相应行。
- 工具有效攻击伤害按 Minecraft 1.20.1 的物品属性计算口径：玩家基础 1 点 + 物品构造器参数 + Tier 攻击伤害加成；最终伤害最低按 0 记。有效攻击速度按玩家基础值 4 + 物品速度修正计算。表中记录最终物品属性，不含其他模组、命途、附魔、药水或状态修饰。
- 怪物基线按实体属性构造器/遗迹监守者当前 profile 中的最大生命、ATTACK_DAMAGE、ARMOR 读取。虚卒原构造器没有单独设置 ARMOR；Stage 3 已显式赋予审定护甲值，Stage 6 仍需核对游戏实例的实际属性。
- 命途等级/差异属性/行迹均由当前 Java 硬编码；本次未发现这些数值的 Forge 配置覆盖。等级、差异属性、行迹可同时生效，必须区分固定加值、百分比与 modifier operation。
- 贴图链按创造栏注册入口 → 物品注册 ID → models/item JSON → textures/item 或 textures/block PNG 核对。BlockItem 可以继承方块贴图。所列资源路径均相对仓库根目录，源码行号标注在对应表格。
