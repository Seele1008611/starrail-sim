# 1.15.0 版本计划：光锥扩充

日期：2026-10-14。状态：**已公开发布。**

## 当前进度

- 三张光锥的物品、原图资源、S1–S5效果、命途条件、叠影配方、遗迹掉落、背包提示和详情页均已接入。

## 二、共同基础属性与叠影

按现有光锥的通用基础属性实现：攻击力 +10%、最大生命值 +5%、护甲值 +5%。叠影等级沿用现有 S1–S5 机制，不另建获取或升级系统。

| 光锥 | 专属效果名 | S1 → S5 数值 |
| --- | --- | --- |
| 你将起身歌唱 | 即兴 | 生命上限 +30% → +60%；击杀后自身攻击力 +10% → +20%；“新声”期间范围内玩家攻击力 +20% → +40% |
| 献给明日的色彩 | 挥墨 | 护甲值 +28% → +68%；击杀后范围伤害 +12% → +20%；击杀回复护甲值的 10% → 20% |
| 向浪花掷下盛夏 | 浪行 | 暴击率 +8% → +20%；攻击速度 +24% → +40%；击杀后攻击力 +10% → +50% |

每张光锥 S2、S3、S4 的具体值按用户提供的数组逐级设置，不以整数取整或二次计算改变原值。

### 1. 你将起身歌唱（记忆）

**即兴**

- 装备者最大生命值提高 30% / 37.5% / 45% / 52.5% / 60%。
- 装备者击杀敌对目标后，使自身攻击力提高 10% / 12.5% / 15% / 17.5% / 20%，并获得持续 20 秒的“新声”；自身攻击加成也持续 20 秒。
- 装备者持有“新声”时，使装备者及其周围 10 格内的其他玩家攻击力提高 20% / 25% / 30% / 35% / 40%。
- 重复击杀刷新自身攻击加成和“新声”的持续时间，不叠层。

**故事**

> 海水漫过足踝，泡沫于月下碎裂。难得的拍摄间隙，少女应邀来到沙滩，前来参加一场小小的篝火晚会。  
> 火光将孩子们的影子拉长，一张张小脸上写满迷茫。「我不会唱」「我唱不好」「我不敢唱」——孩子们望向她，怯生生道：「知更鸟姐姐，我们该怎么办？」  
> 她微微一笑，用指尖轻触琴弦，替代回答。  
> 「来，跟着我——」  
> 第一声拨弦被海风吞没，第二声调律便有了形状。浪花拍岸、灯火明灭，她启唇，低吟轻歌，将胸中那片澄澈的晴空倾倒而出。  
> 「当你们不知道该怎么唱的时候，就听听自己心里的旋律。」  
> 起初只是零落的声调，后来渐渐声调有了轮廓，轮廓开始呼吸。她唱着，他们唱着，直至夏风拂过。  
> 「听，这就是我们心里的歌呀。它一直在那里，等待被听见。」  
> 她听见了，于是，她温柔地祝愿道：  
> 「起身歌唱，随后，振翅飞翔吧。」

### 2. 献给明日的色彩（欢愉）

**挥墨**

- 装备者护甲值提高 28% / 36% / 48% / 56% / 68%。
- 装备者击杀敌对目标后，获得“墨笔”，使自身及周围 10 格内的其他玩家造成的伤害提高 12% / 14% / 16% / 18% / 20%，持续 10 秒。
- 触发时，为装备者及其周围 10 格内的其他玩家各回复一次生命值，回复量等于装备者当前护甲值的 10% / 12% / 15% / 17% / 20%。

**故事**

> 「错笔已修正，参数已调整。」  
> 她曾试图拟合画作中海的曲线，萃取水的形意，解析星星点点的浮沫。  
> 一次又一次，绘笔下开出无数朵浪花，但都不是她想象中的那朵。  
> 「我想为众人作画：并非描摹他们的脚步，而是为他们绘出前路。」  
> 一笔挥出，她为饥渴的孩子带去庇护。  
> 墨色晕染，她用笔触织补天地的裂缝。

> 无数个昨日，她为他人描绘未来——  
> 苍白的，黯淡的，染上希望的色彩。  
> 恍然回首，她落下的每一笔，也刻画着她心中的「真珠」。

### 3. 向浪花掷下盛夏（欢愉）

**浪行**

- 装备者暴击率提高 8% / 11% / 14% / 17% / 20%。
- 装备者施放攻击时获得“风口”，攻击速度提高 24% / 28% / 32% / 36% / 40%，持续 3 秒。
- 装备者击杀敌对目标时，额外获得“潮流”，攻击力提高 10% / 20% / 30% / 40% / 50%，持续 10 秒。
- 攻击触发沿用现有正伤害 `LivingHurtEvent` 规则；“风口”和“潮流”重复触发时刷新持续时间，不累加层数。

**故事**

> 「惊涛骇浪意味着风险重重，风险重重更意味着回报颇丰。」

> 「既然浪潮已至，何不看看它究竟能掀起什么？」

## 三、配套建议

### 建议纳入：光锥选择器按命途筛选

现有替换界面支持名称和物品 ID 搜索，但没有命途筛选。加入两张欢愉和一张记忆光锥后，可增加与模组界面一致的命途下拉筛选，方便玩家从背包候选中定位光锥；不增加页面，也不改变直接替换流程。

### 维持获取与养成边界

本版不新增抽取池、兑换商店或通用叠影材料。三张新光锥沿用现有遗迹宝箱掉落：对应命途遗迹池加入本命途光锥，普通遗迹池也加入三张光锥；叠影继续使用现有“两张同名光锥合成高一级”的配方。

## 四、实现约束与待定项

1. 三张光锥各使用独立物品 ID，保留旧光锥 ID 和既有存档数据；专属效果只在对应命途生效。
2. 范围效果只作用于同一维度、10 格范围内的其他玩家，装备者本人单独结算一次；不得因多个持有者重复给同一目标叠加同一来源的增益。
3. “即兴”的自身攻击加成与“新声”持续 20 秒；重复击杀刷新持续时间，不叠层。其他有时长的效果也按刷新、不叠层处理，除非实现前发现现有战斗规则要求不同处理。
4. “挥墨”治疗按触发时装备者当前护甲值计算，并通过正常治疗事件结算；受治疗者不能超过最大生命值。
5. “施放攻击”的触发时点沿用项目现有战斗事件定义；需要明确是否只有命中才触发“风口”，避免把一次蓄力或持续攻击错误重复计数。
6. 补齐中英文名称、基础属性、S1–S5 效果和完整故事文本。长故事在物品提示和光锥详情界面中不得溢出或遮挡操作区域。
7. 沿用现有光锥资源流程，将用户已处理好的 PNG 原样接入游戏贴图和模型；不再进行抠图、补边或像素化，也不覆盖素材文件夹中的原图。按需要校准卡面展示焦点，并接入创造物品栏、Curios 光锥栏、替换界面及命途标签。
8. 光锥装备、替换和存档重进后状态一致；卸下或更换光锥、切换命途后不残留专属属性或玩家增益。

## 五、一次性验收重点

1. 三张光锥的物品贴图与卡面使用已提供图片，名称、命途、通用基础属性和 S1–S5 数值正确；卡面无拉伸、黑底或主体裁切。
2. 击杀触发、持续时间、刷新规则、10 格玩家范围、治疗量与攻击速度效果符合最终规则；单人和范围内多玩家都只结算预期次数。
3. 换命途、换装、卸下光锥及存档重进后，临时增益和属性不会残留、丢失或重复叠加。
4. 长故事、属性与效果说明在背包物品提示和光锥详情界面完整可读，中英文资源齐全。
5. 命途筛选与名称搜索组合正确；欢愉、记忆、其余命途和“其他”分类结果无误。
6. 若具备联机测试条件，检查范围增益和治疗由服务端结算、多人不会重复触发；否则如实记录为未测试。
