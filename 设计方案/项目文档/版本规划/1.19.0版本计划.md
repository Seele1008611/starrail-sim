# 1.19.0 版本计划：命途遗境海洋生态

日期：2026-10-19；进度更新：2026-10-20。当前状态：**阶段 0 至阶段 5 的单机内容验收均已完成，1.19.0 已正式发布；多人服务器同步尚未实测，单独记录为覆盖范围限制。**

## 一、版本目标

1.18.0 已完成命途遗境的基础自然生态、生存循环、矿物与装备成长。本版沿着“把命途遗境发展成可长期探索和定居的自然维度”继续扩展，重点新增一套相互衔接的海洋与沙滩群系，并补齐陆地、海岸、浅海到深海的环境过渡。

本版不是单纯给水体换色，也不新增一整套装备成长阶级。海洋应当有清楚的地形层次、可持续的本地资源、值得潜水探索的地点，并与晴穹草甸、流萤林地共同组成维度生态。本版循环为：**沿海岸发现海域 → 从岛屿与浅海建立安全据点 → 采集海生植物和食物 → 沿海底地形探索洞穴与自然资源点 → 带回材料继续建造和定居。**

### 延续的设计原则

- 命途遗境仍以自然世界为主体，星空与星轨元素作为局部点缀；水、沙岸、海底岩层和海洋植物须有自然的色彩与分布层次。
- 本地生态资源可以因群系而异，但霞铜、曦铁、曜金、星炭、星琼、古老梦华等维度成长资源应继续作为共享资源，在本版新增海洋群系中也有合理获取路径，不制造群系专属的装备进阶门槛。
- 海洋群系的基础食物、木材和照明应有稳定来源；不得要求玩家先找到遗迹、稀有战利品或另一群系才能开始生存。
- 潜水挑战使用原版水下探索规则，不增加氧气条、口渴条等新的强制生存系统。地形应给玩家可读的路线与阶段性安全点。
- 对生成进行多种子、多个区域的采样；海底砾石、沙土或特色方块不得错误铺满陆地表面，也不得因特征配置而跨群系泛滥。

## 二、1.18.0 基线与本版边界

- **现有基线：**命途遗境已有晴穹草甸和流萤林地两个自然群系；地表、矿物、树木、作物、食物和基础生存循环已接入。普通遗迹、命途遗迹和遗器决斗场已有生成与定位流程。
- **本版新增：**海洋群系及与其配套相邻的沙滩群系；包含海岸/海底地形、海洋生态资源、可持续食物、自然探索地形和必要的指南/定位整合。
- **明确不纳入：**改造既有普通遗迹、命途遗迹或遗器决斗场的蓝图、结构方块材料、外观与奖励；新增一档装备成长；把共享成长矿物锁定在海洋群系；制作大型海底建筑结构集或复杂水下副本。
- 现有结构的生成配置也不因海洋群系接入而自动调整。本版如发现结构与新海岸地形存在直接冲突，先修正生成避让或地形兼容问题，不替换结构内容。
- 新群系只影响更新后生成的区块；已经生成的地形不会被自动重做。世界存档迁移行为在阶段 0 核对，并在测试说明中告知玩家。

## 三、新群系方向：星潮海域与配套澄沙海滩

本版新增两个群系键：海洋与沙滩；浅海、礁群、深水和海沟是海洋群系内部的地貌分区，不再额外拆成多个群系。沙滩作为独立但与海洋成对设计的过渡群系，通常沿海洋边缘生成，把草甸/林地连接到浅海；它不是单纯给海岸方块换成沙子，也不应无缘无故散落在内陆。整体气质为明亮、开阔、有远近层次的自然海域与海岸；星光反射、微光生物或少量晶体可以作为识别点，不把海面和海底整体做成荧光蓝紫色。

| 群系/区域层次 | 视觉与地形方向 | 玩法用途 |
| --- | --- | --- |
| 澄沙海滩 | 沿海洋边缘形成连续或自然分段的沙岸、砾石岸、潮池和浅水湾，并与草甸/林地的岸线平缓相接；避免笔直硬边、悬崖断层和孤立内陆沙滩 | 登陆、辨认海岸方向、收集基础资源并建立安全据点；作为陆地进入海洋的主要缓冲带 |
| 星潮海域：浅海与礁群 | 水深适中，分布海生植物、礁石、浅水洞口与近岸小岛；疏密自然，不采用均匀网格摆放 | 提供低风险采集、食物来源和从海滩逐步潜水的路线 |
| 星潮海域：深水与海沟 | 以更深的海底盆地、岩壁、洞穴入口或少量地质节点形成纵深；危险程度来自能见度、路线和深度，而不是突然堆叠高伤害敌人 | 作为可选的进阶探索区域；不将基础生存资源或装备必需材料藏在最深处 |

沙滩与海洋应在群系布局和地形生成上协同设计：沙滩应靠近海洋，海滩后方自然接入晴穹草甸或流萤林地，浅海再逐步过渡到深海。不是每段海岸都必须完全相同；可以有少量砾石岸、岩岸等地形变化，但主要沙滩群系必须可辨认且确实承担海陆过渡功能。具体海域/沙滩比例、海底高度与群系布局需通过世界采样决定，不在规划阶段锁定数值。

### 生成实现基线与主要技术风险

当前命途遗境使用 `multi_noise` 群系源，晴穹草甸和流萤林地按大陆性噪声区间分布；维度地形共用 `the_path` 噪声设置，海平面为 Y=63，地表规则再按群系键选择表层方块。因此，单纯新增海洋和沙滩的群系 JSON 与参数区间，不能保证沙滩贴着海洋，也不能保证海床自然低于水面。

首轮参数原型按大陆性噪声划分海洋 `[-1.0, -0.19]`、沙滩 `[-0.19, -0.11]`，陆地从 `-0.11` 起；陆地范围内再以湿度噪声 `[-1.0, 0.0]` 和 `[0.0, 1.0]` 区分晴穹草甸与流萤林地。它们只是用于采样的起始值，不能在未看多个新世界样本前当作最终频率承诺。

- 阶段 0 先做小规模世界生成验证：观察陆地、沙滩、浅海和深海在多处边界是否形成预期关系，再决定群系参数、噪声路由/地形曲线和表层规则的具体实现。
- 沙滩分布须跟海陆地形信号协同；若现有 `multi_noise` 参数无法稳定形成海岸相邻关系，应先解决群系布局方法，再批量接入植物、矿物和装饰特征。
- 海洋地形须形成可容纳水体的海盆与海床，不通过在陆地表面铺水、把海平面整体抬高或用大量方块特征填坑来伪造海洋。
- 沙滩、海床和既有草甸/林地各自使用明确的表面材质规则。河床砾只作为少量河流/海岸地质变化，不得因复用特征而覆盖大面积陆地、整片沙滩或整个海床。
- 若需要改动维度共享噪声设置，先验证两个已发布群系的地形没有被连带破坏；1.19.0 的海岸方案不得以退化现有陆地生态为代价。

## 四、配套生态与可玩内容

### 1. 海生植物与食物

- 新增少量具有辨识度的海生植物，优先覆盖装饰、可再生采集和食物用途，不为追求数量加入近似重复的方块。
- 至少形成一条稳定、可持续的海洋食物来源；采集方式、是否能种植或扩繁，在阶段 0 根据游戏内操作体验定稿。
- 海岸或岛屿区域要能稳定取得木材和基础建造材料。优先复用晴穗树、流萤树或既有基础资源配置，不为满足海洋开局而预设必须新增第三套木材组。
- 海洋植物可用于装饰、染料、堆肥或料理；不成为星琼/古老梦华装备升级材料的唯一来源。

### 2. 海底自然探索点

本版优先做地貌与自然生成特征，而不是大型结构：例如海底洞穴、气泡泉、礁群、海床晶簇或地热喷口。阶段 0 从中选择少量互相配合的内容，避免每种都做成独立系统。

- 自然探索点应该从海底地形中自然长出，并有清晰的视觉提示；不能散布成固定间距、每区块重复的装饰阵列。
- 可以提供建材、食物、装饰或非关键探索奖励。任何成长必需品仍须能在其他现有群系获取。
- 如实现气泡或通风安全点，须复用玩家容易理解的原版交互，不以此强制玩家携带额外消耗品。
- 不新增会被误认为普通遗迹或决斗场的巨型建筑；不改旧结构模板、材料或生成概率。

### 3. 生物与环境表现

- 先配置原版水生生物在新群系中的合理生成，并核对陆生生物不会大量刷在海床或深水中。
- 可选新增一种代表性、低维护成本的被动海洋生物，负责群系识别或提供非关键生态反馈；若实体建模、动画或同步风险挤压地形与资源验收，则推迟到后续版本，不作为本版主线阻塞项。
- 可用水色、雾色、环境音、气泡/水下粒子和少量发光点建立海域气氛；整体水下可读性须足以看清采集物和回程路线。
- 不以新增 Boss 或高密度敌对生物作为海洋群系的主要内容来源。

### 4. 推荐的首轮内容规模

为让海岸生态有辨识度，同时把生成与验收工作控制在本版范围内，阶段 0 采用以下最小内容组合进入原型验证。名称已随实现和游戏内指南定稿：

| 内容 | 首轮建议 | 设计边界 |
| --- | --- | --- |
| 沙滩表面 | 优先复用现有澄溪砂；局部用河床砾形成少量砾石岸或冲积斑块 | 先验证材质在海滩和水下的连铺效果；只有视觉/用途确有差异时才新增海滨砂方块 |
| 海岸植物 | 低矮潮汐草，以及新增的澄沙铃花；后者以蓝白花瓣和金色花心形成海滩识别点 | 潮汐草可在海滩砂/砾上生长；澄沙铃花只扎根于澄沙海滩群系内的本模组澄溪砂，稀疏自然生成，可堆肥并可制浅蓝染料；不覆盖普通沙地、砾地、海床或其他群系 |
| 海生植物 | 一种可在水下生长和扩繁的“星潮藻”类植物 | 负责海底视觉识别，并提供可持续采集来源 |
| 海洋食物 | 让海生植物或原版水生生物支撑一条稳定食物循环；可加入一种简单烹饪品 | 不能要求稀有掉落、宝箱或专属实体才能吃饱；数值与现有食物接近 |
| 水下自然节点 | 首轮只选一种主视觉节点，例如礁群或不伤害玩家的气泡泉 | 作为路线标记和可选探索点；不扩成大型遗迹或独立副本 |
| 海洋生物 | 先调好原版水生生物生成；专属被动生物列为可选内容 | 专属生物若增加模型/同步工作，应让位给海岸与海底生成验收 |

沙滩作为过渡群系，不需要被塞满树木和食物。可持续木材应由海滩背侧附近的现有草甸/林地或近岸岛屿提供；生成和游玩测试需确认玩家能通过清楚、短距离、可步行的路线抵达，不被水道或悬崖隔断。

### 阶段 0 执行基线

- 新增两个群系键：`star_tide_ocean` 与 `clear_sand_beach`；浅海和深海保留为海洋内部的地形层次。
- 海滩优先复用澄溪砂作为主体地表，河床砾只用于小比例的岸边变化；海床以砂质与裸露本地岩层形成分布，不将河床砾当作默认海床。
- 首轮原型包含一种潮间带装饰植物、一种可再生海生植物和一种可烹饪食物：潮汐草、星潮藻和烤星潮藻；掉落、种植和饱食值已在阶段 2 接入并通过验收。
- 澄沙铃花是阶段 2 增补的海滩装饰植物：蓝白花瓣、金色花心；仅可种植在澄沙海滩群系的本模组澄溪砂上，自然稀疏生成于该群系；采集后可重新种植，可堆肥，并可制作浅蓝染料。不得改动潮汐草原有的砂/砾适生范围。
- 先配置原版水生生物和海底洞穴；专属海洋生物为可选扩展，不作为本版基础范围。
- 阶段 3 首轮主视觉水下节点选用稀疏的上升气泡泉；不同时加入礁群、大型海底建筑或副本。
- 不新增装备阶位或成长矿物。共享矿物进入两个新群系的合适岩层；普通遗迹与决斗场继续使用现有模板，仅在通过地形适配检查的陆地区域生成。
- 世界生成原型先复用现有 Y=63 海平面和地形密度场，验证海陆/海岸/海床对应关系；若不足以形成合理海岸，再提出最小噪声设置调整并检查对晴穹草甸、流萤林地的影响。

## 五、资源与平衡规则

- 海岸与海洋组合应允许玩家获得可持续的本地食物、基础建材和照明燃料；玩家可以在海滩、沿海浅滩或岛屿安全起步，再选择是否深入水下。
- 海底可有特色材料或矿物露头，但主要用途是建造、装饰、食物或可选探索奖励；不可用海洋专属材料抬高既有装备等级。
- 霞铜、曦铁、曜金、谐振晶、记忆晶、星髓、星炭、星琼和古老梦华继续遵循维度共享资源原则。可调整不同地质宿主和海底露头表现，但要验证玩家在四个群系的可开采岩层中都有正常获取路径。
- 若水下生成矿物会导致矿脉暴露成片、刷在沙面或难以辨认，应优先调整宿主岩层与生成条件，不通过增加稀有度掩盖分布错误。
- 海洋食物的饱食度、恢复效果和生产速度与现有晨露莓、林息豆及原版食物保持平衡；不得让新食物成为必需工具或材料的软锁。

## 六、实施阶段与验收

### 阶段 0：定稿海洋生态与版本清单

- 确认海洋与配套沙滩的正式名称、色彩方向、海岸/浅海/深海层次及与两个现有群系的邻接方式；决定是否需要少量砾石岸或岩岸变体。
- 确认新增方块、植物、食物和自然探索点的最小清单；为每项写清生成位置、采集方法、用途和可持续来源。
- 使用测试种子验证当前 `multi_noise` 群系源、Y=63 海平面和表面规则能否形成“草地/林地—沙滩—浅海—深海”连续地貌；若不能，先定技术方案再冻结资产清单。
- 确认海洋是否加入一种新被动生物；同时明确不修改既有遗迹/决斗场模板、材料和生成概率。
- 绘制海洋的“海岸资源 → 据点与食物 → 浅海探索 → 深水可选探索”循环，并核对共享矿物规则。
- **阶段验收：**内容清单不依赖结构战利品；不存在新的装备阶位或群系专属成长门槛；每项新内容有明确用途和验收方法。

#### 阶段 0 首轮地形采样记录（2026-10-19）

- 用户在新世界实测确认：海床低于水面、海岸与海洋相邻生成、晴穹草甸和流萤林地均正常。
- 这通过了首轮海陆关系与既有陆地群系兼容性检查；更广范围的海岸形态、海湾/岛屿/深水分布和多种子表现仍由阶段 1 继续验收。
- 首轮采样沿用本计划中的海洋和沙滩方案；后续实现将名称定为星潮海域、澄沙海滩，并接入潮汐草、星潮藻、烤星潮藻、澄沙铃花与上升气泡泉。

#### 阶段 1 多种子验收记录（2026-10-19）

- 用户使用多个种子检查后确认：海洋与沙滩分布、海岸衔接和既有陆地群系过渡均正常。
- 阶段 1 生成验收通过；后续发现海底局部问题时仍按阶段 3/5 的地质与整体验收继续处理，不将本次抽测扩大为所有地形细节均已验证。

### 阶段 1：生成海岸、岛屿与海底地形

- 接入海洋群系及其与晴穹草甸、流萤林地的地表过渡。
- 按阶段 0 通过的方案配置海洋与沙滩群系区间、海陆地形信号和表面材质规则；保留陆地、沙滩、浅海与深海的独立排查手段。
