# 1.8.0 版本计划

## 版本定位

**主题：九命途战斗特效与韧性击破反馈。**

1.7.0 已完成九命途行迹材料的遗迹获取循环并通过游戏内验收。1.8.0 转向战斗表现：为九种命途的代表性触发技，以及通用的韧性削减和击破，设计清晰、短促、符合 Minecraft 像素风格的粒子反馈。

开发顺序沿用已验证的流程：先在 HTML 原型中确定构图、颜色、节奏和尺寸，再将确认后的表现接入游戏。该版本的特效不改变触发条件、伤害、冷却或其他战斗数值。

## 版本目标

1. 九种命途的关键触发效果可以通过颜色、形状和运动方式区分。
2. 韧性削减和击破有清楚的即时反馈，击破表现比普通韧性削减更醒目。
3. 特效不遮挡玩家、目标、伤害数字和战斗界面，近距离及常见视角下仍能辨认。
4. 特效只在服务端确认机制触发后播放，并同步给相关玩家；客户端不自行判定战斗结果。
5. 遵守 Minecraft 粒子设置，控制单次粒子量和重复触发频率，避免战斗中堆积。

## 特效范围

### 九命途代表性触发

| 命途 | 计划表现的触发点 | 视觉方向 |
| --- | --- | --- |
| 巡猎 | 追猎一击、7 级“逆时追猎” | 集中指向目标的迅捷轨迹与命中闪光；“逆时追猎”使用更强的一次性终结脉冲 |
| 存护 | “护壁”生效、成功格挡后的“反震” | 盾形/环形护持光效；反震以短促向外扩散的冲击表现 |
| 毁灭 | 低生命值下的“怒火”“焚身”和“绝境”强化 | 由内向外的炽热裂纹或火星，强化攻击命中时集中爆发 |
| 智识 | “知识回响”及“终局推演” | 几何标记连接邻近目标；强化范围攻击呈现清晰的扩散层次 |
| 虚无 | 侵蚀施加、扩散及标记击杀后的“虚无终局” | 紫色/暗色粒子附着目标，扩散时短暂连线，终局时向周围释放回响 |
| 同谐 | 共鸣获得、余响强化攻击及协奏回响 | 柔和的环形波纹与节拍式光点，表现增益和队伍支援 |
| 丰饶 | 治疗、生生不息、甘露护盾及“慈航”救援 | 向上回升的生命光点；护盾与紧急救援采用更明显的包覆/绽放表现 |
| 记忆 | 记录目标、同一目标回响及“永恒回响” | 冰蓝色记忆微粒从攻击者与目标间建立联系，回响时沿联系折返或脉冲 |
| 欢愉 | 连击爆发、每六次连击的“终极欢愉” | 明快、短促的跳跃式粒子；普通爆发与强化爆发有不同规模和层次 |

名称与机制依据当前指南和服务代码。巡猎技能名为“逆时追猎”；“逆时猎杀”是减少该技能冷却时间的行迹被动。

### 通用韧性反馈

- 每次成功削减韧性：在目标附近显示轻量、短促的命中反馈，不重复播放大型爆发。
- 韧性归零：播放一段更醒目的破韧效果，例如收束后碎裂的环形冲击，并与已有破韧数字及状态提示协调。
- 韧性恢复、目标死亡、无效攻击不播放击破特效。
- 如果攻击者已踏上命途，可用该命途主题色做轻微点缀；无命途玩家使用统一中性色。

## HTML 原型阶段

先建立 1.8.0 战斗特效原型页，用模拟目标和控制按钮展示，不调用游戏逻辑。

- 支持切换九命途并触发各自代表性效果。
- 可单独播放“韧性削减”和“韧性击破”，比较两者的强弱层级。
- 呈现目标周围粒子的起点、方向、持续时间、颜色和大小，避免只看静态贴图。
- 将特效放进接近游戏内视距的场景，并保留生命条、伤害数字等占位元素，检查遮挡和辨识度。
- 提供默认粒子量与低粒子量预览，确定降级方式。
- 先由用户验收整体风格和九命途差异，再开始游戏内接入。

原型建议存放在 `设计方案/UI设计/1.8.0战斗特效原型/`。优先复用项目现有图标和主题色，不额外下载素材。

## 游戏内实现方向

1. 按 HTML 验收结果确定粒子类型；优先使用 Minecraft/Forge 已有粒子，只有现有类型无法表达时再注册少量自定义粒子。
2. 在各机制已经确认触发的位置发出特效事件，不复制或重写路径机制。
3. 由服务端确认触发和目标，再向相关客户端发送粒子表现；避免客户端状态造成重复触发或作弊入口。
4. 复用命途颜色和现有战斗消息/伤害数字的时间关系，让特效补充反馈，不替代文字或数值信息。
5. 控制粒子数量、范围和持续时间，并检查原版粒子密度设置下的表现与性能。

## 验收范围

### HTML 验收

- 九种命途的触发效果在不看名称时也能凭主要色彩或运动方向区分。
- 巡猎“逆时追猎”等代表性强化触发，与普通命中反馈有明显层级差异。
- 普通韧性削减和韧性击破一眼可区分。
- 近距离、常见视距、目标周边有多个实体时不明显遮挡战斗信息。
- 低粒子量模式仍保留触发方向和强弱层级。

### 游戏内手动验收

- 九命途各自只在正确触发时播放对应效果，未踏上命途时使用统一样式。
- 每种关键效果与当前机制触发次数一致，不因事件重复监听而播放两次。
- 韧性削减、最后一击破韧、击破冷却/恢复期间分别表现正确。
- 单人及多人视角下，攻击者和附近观察者看到一致的触发结果。
- 原版粒子设置调整后粒子量符合设置；持续战斗中无明显粒子堆积或帧率异常。
- 现有伤害、韧性、冷却、行迹和光锥机制保持不变。

## 暂不纳入 1.8.0

- 不改动九命途触发技能的数值、条件或冷却。
- 不重做伤害数字、行迹 UI、首领模型或战斗音效。
- 不为所有光锥被动和所有状态效果单独制作特效；先覆盖九命途代表性触发及韧性击破。
- 不引入大型纹理包或外部下载素材。

## 建议实施顺序

1. 以本计划为范围基线，先制作九命途与通用破韧的 HTML 动效原型。
2. 用户验收原型，收敛配色、粒子量、持续时间和视距。
3. 先在巡猎“逆时追猎”和通用韧性击破上接入游戏，验证粒子同步、遮挡和性能。
4. 按同一套触发事件接口接入其余八种命途，逐个进行游戏内检查。
5. 完成九命途、粒子设置、多人同步和既有战斗逻辑回归验收。
6. 用户确认通过后构建并发布 1.8.0。
