# 1.5.0 版本规划

## 版本定位

完善光锥饰品栏与九种命途试炼启始道具的视觉表现和使用说明。1.5.0 以物品呈现与易用性为主，不扩展试炼玩法或调整现有数值。

## 目标内容

### 1. Curios 光锥栏位图标

- 为空置的光锥栏位制作专属透明底图标，保持 Minecraft 像素风格。
- 图标缩放后仍能辨认；栏位装备光锥时正常显示已装备物品。
- 只改图标表现，不改饰品栏位标识、注册、装备规则和效果。

### 2. 九种命途试炼启始道具

- 为巡猎、存护、丰饶、毁灭、智识、虚无、同谐、记忆、欢愉设计一组风格统一、彼此易辨认的图标。
- 通过命途符号、轮廓和配色共同区分，不仅依赖颜色。
- 显示对应命途的名称；悬浮说明写清道具用途、开启条件和消耗时机。
- 保持现有单一物品注册与 `Path` 数据区分方式，不拆分为九个物品，不改奖励来源、试炼目标、计时、消耗和奖励逻辑。

### 3. 配套说明与物品整理

- 在命途指南或物品提示中说明启始道具用于开启对应命途的首次试炼，以及失败或超时后的道具处理规则。
- 检查创造模式物品列表中九种变体的名称、外观和命途对应关系，便于查找和测试。
- 若说明内容与现有实际行为不一致，以当前实现为准，先记录差异，不在本版本规划中擅自改变玩法规则。

## 暂不纳入

- 新增命途、试炼目标、奖励或战斗机制。
- 调整现有试炼难度、数值、奖励概率、获取方式或消耗规则。
- 将九种变体改为九个独立注册物品。
- 大规模重做命途指南或角色 UI。

## 验收标准

1. 光锥栏位为空时显示专属图标；装备光锥后显示装备图标，装备、取下和光锥效果均正常。
2. 九种启始道具的名称、图标和内部命途一一对应，悬浮提示易懂且不误导。
3. 错误命途、未满足条件或无法启动试炼时不误消耗道具；成功启动时的消耗与当前行为一致。
4. 试炼奖励、试炼目标和超时处理保持现有行为。
5. 检查常用 GUI 缩放下的图标辨识度，并完成单人客户端和服务端启动验收。

## 实施顺序

1. 先确定光锥栏位图标与九种命途道具的像素图标方向。
2. 完成图标、名称和悬浮说明。
3. 补齐指南说明并整理创造模式中的变体展示。
4. 按验收标准进行客户端与服务端检查。
