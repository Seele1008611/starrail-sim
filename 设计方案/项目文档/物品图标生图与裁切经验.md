# 物品图标生图与裁切经验

> **优先看本页前半部分。** 下面标注“核心经验”的流程是当前有效做法；具体试作记录只供查阅。

## ⭐ 核心经验（优先遵循）

1. **先确认材质配色。** 查看项目内原矿、锭或方块素材，用文字描述颜色；不要只按材料英文名猜颜色。除非用户明确要求，不把旧图作为生图参考图。
2. **物品图标一律用方形 3×3 母稿。** 需要九件时每格放一个不同物品；只需要一件时也必须生成3×3母稿，只在一格放目标图标，其余八格完全留空透明，再从占用格裁切。这样避免让单个图标独占整张生成画布，减小裁出文件的体积。每件按16×16逻辑像素、Minecraft方块像素风格设计。只有方块贴图例外：按方块贴图规范单独生成完整方形材质，不套九宫格。
3. **逐张检查母稿再归档。** 确认九件齐全且不重复，检查工具类型、材质颜色、透明背景、四边与底排有没有被裁断。生图模型不一定遵守“居中”“不裁切”等提示，不能跳过检查。
4. **裁切时保留原像素，不缩到16×16。** 用 Alpha≥180 的八邻域主体识别；靴子合并两只。检查主体是否越过虚拟格线，若越界就从整张母稿提取完整连通区域，不能硬切单格。主体 mask 扩张2像素保留边缘，去掉外部杂点后居中放入正方形透明画布，四周留4像素内边距，再做 PNG 无损优化。
5. **预览不是运行时贴图。** 候选需逐件检查握柄连接、剑尖、镐头两端、护甲边缘和透明底。用户审阅通过前不覆盖 `src/main/resources`；不把放大预览或高分辨率原稿称为游戏内正式贴图。

## 可复用提示词模板

```text
Create one square transparent sprite sheet with exactly nine distinct complete Minecraft-style inventory icons in a 3 by 3 grid. Each icon is designed as a 16 by 16 logical-pixel texture using crisp square pixels and simple blocky Minecraft style. In reading order: [ITEM 1], [ITEM 2], [ITEM 3]; [ITEM 4], [ITEM 5], [ITEM 6]; [ITEM 7], [ITEM 8], [ITEM 9]. Put exactly one unique recognizable item in each cell. Keep every complete silhouette centered and inside its cell with clear transparent margins; no cropped tips, handles, tool heads, armor edges, or boots. Use [PROJECT-CORRECT MATERIAL PALETTE] and dark brown handles where applicable. No duplicates, extra objects, text, labels, borders, or scene background.
```

**镐的补充句：** `The pickaxe has a full crosswise head with both ends visible and a long diagonal handle.`

透明背景需在工具参数中启用；生图后仍要检查实际 Alpha 和背景，不要只看提示词。

### 试作中得到的补充结论

- 16×16缩放可能使细柄断裂、轮廓变粗；当前保留母稿原像素的无缩放提取方式。
- 体积下降主要来自裁掉空白和噪点；相同像素的 PNG 无损重编码通常只减少少量，不能承诺达到60%。
- 出现格边贴近、行列裁断或配色不符时，淘汰该稿或重裁；不要把缺陷带入项目素材。
- 本段阶段进度数字是早期记录；当前候选数量与审阅状态以[1.26.0版本计划](版本规划/1.26.0版本计划.md)为准。
