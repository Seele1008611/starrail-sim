## 项目概况

- **项目：** 崩铁小模拟（Star Rail Sim），Minecraft Forge RPG 模组。
- **当前正式版：** 1.6.0，面向 Minecraft 1.20.1、Java 17、Forge 47.x，依赖 Curios API 5.14.1。
- **主要玩法：** 受《崩坏：星穹铁道》启发的九条命途、角色属性与战斗、光锥/Curios 装备槽、命途试炼与晋阶、命途遗迹寻迹、指南，以及对应的 UI。
- **已发布版本脉络：** 1.4.0 完成游戏内 UI 改版；1.5.0 增加光锥饰品槽专属图标和九种命途试炼凭证图标、说明；1.6.0 增加九命途行迹树。正式版功能与验收记录见根目录 `README.md`、`CHANGELOG.md` 和 `releases/`。
- **开发环境：** Windows PowerShell，项目自带 Gradle Wrapper；本地离线编译命令见下方。

## 1.6.0 目标与设计依据

1.6.0 为九条命途增加各自独立的行迹树：六个属性节点、三个被动节点；树形、分支曲线、主题色和背景命途图标分别体现命途特征。每条命途用对应物品升级。切换命途后保留各自进度，但只启用当前命途的行迹属性和被动。

- 原型入口：`设计方案/UI设计/1.6.0行迹原型/巡猎行迹设计图.html`，配套 `巡猎行迹.css`、`巡猎行迹.js`。虽然文件名保留“巡猎”，原型中已有九条命途的设计。
- 设计表：`设计方案/项目文档/1.6.0巡猎行迹设计表.md`。巡猎先作为节点与交互样板；九条命途总属性、等级门槛、前置关系、被动说明及材料见该表和 HTML 数据。
- 用户提供了九张分支参考图，顺序为：欢愉、虚无、同谐、智识、毁灭、记忆、巡猎、丰饶、存护。游戏内描线布局按参考图和原型画布比例适配。
- 行迹材料对应：欢愉《绒绒号》典藏版合集、记忆阿赖耶华、虚无沉沦黑曜、存护琥珀的坚守、毁灭净世残刃、同谐群星乐章、丰饶永恒之花、智识智识之钥、巡猎逐星之矢。
- 每棵树总计消耗 33 个所属命途材料；总属性和节点级别的分配方案已确认。行迹重置返还被撤销节点的对应材料，回退节点会连带回退依赖节点。

## 常用命令

在仓库根目录 PowerShell 中：

```powershell
.\gradlew.bat --offline --no-daemon "-Dnet.minecraftforge.gradle.check.certs=false" compileJava processResources
.\gradlew.bat --offline --no-daemon "-Dnet.minecraftforge.gradle.check.certs=false" runClient
```

用户说“启动测试客户端”时再运行 `runClient`。启动前先查看是否已有项目客户端进程；客户端退出后保留日志供排查，不要清理用户的存档或工作区素材。
