# 1.23.0 阶段 1：正式地貌资源接入

日期：2026-10-23。阶段 0 的原型测试已由用户确认通过；本记录跟踪原型配置接入正式资源后的源码检查。**本阶段没有构建或启动 1.23.0 模组，也没有对新资源做实机验收。**

## 接入内容

- `dimension/the_path.json` 新增星砾高地与静潮泽地各两条路由，覆盖 `depth=0` 与 `depth=1`。四个新参数盒子从既有草甸/林地的气候范围中切出；海洋、海滩和星脉洞窟路由保留。
- `worldgen/biome/` 接入两个通过阶段 0 原型的群系定义。
- `worldgen/noise_settings/the_path.json` 接入群系限定的高地/泽地表面分支，沿用阶段 0 的表面噪声阈值，不改 `noise_router`、密度函数、海平面或噪声地形。
- 维度、噪声和两个群系资源在首次正式接入时与 `libs/starrail_sim-1.23.0-phase0-worldgen.zip` 的对应文件逐字节一致。复核 SHA-256：

## 验收范围与剩余工作

- 已复核 25 条维度群系路由；原有海洋、海滩与洞穴的参数未被新地表窗口覆盖。
- 首次接入版本的四份 JSON 均可解析且与用户验收的阶段 0 包一致。阶段 2 的特征文件和群系植物列表已追加，须随方块注册与贴图一并加载。
- 当前需在 1.23.0 测试 JAR 上检查数据包重载、表面材料、植物/碎砾生成、与海岸和洞穴的交界，以及多种子分布。此记录不把离线采样或 JSON 静态检查表述为实机验证。
