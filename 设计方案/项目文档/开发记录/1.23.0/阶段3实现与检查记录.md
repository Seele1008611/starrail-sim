# 1.23.0 阶段 3：探索与结构兼容实现记录

日期：2026-10-23。两个新群系的探索入口、发现进度、玩家指南、管理员定位和生成群系资格已接入；静态检查、`compileJava` 与 `1.23.0-test.jar` 构建已完成。**该测试包尚未在游戏内加载，实际结构生成仍未验收。**

## 探索记录与命令

- `StarRailExplorationService` 现在识别 `star_scree_highlands` 与 `stilltide_marsh`，继续写入现有的发现群系集合，并通过路径状态包同步客户端档案。
- 区域发现掩码从 `int` 扩为 `long`：星砾高地使用 bit 32，静潮泽地使用 bit 64。`PathStatePacket` 相应以 long 编解码；网络协议号由 17 升至 18，避免新旧字段布局的客户端/服务端被视为兼容。
- 行旅档案新增两行；旧档 advancement 迁移版本升到 2，并按玩家已保存的群系发现记录补发新进度。
- 新增 `star_scree_highlands`、`stilltide_marsh` 两个群系发现 advancement，均使用原版 location criterion；增加 `/starrail dimension locate region star_scree_highlands` 与 `/starrail dimension locate region stilltide_marsh`。
- 中英文指南与进度文字新增两群系说明、采集/种植规则和可用定位 literal；共享矿物说明更新为七个群系。

## 结构群系资格

阶段 0 的采样表明两个新群系属于可步行陆地：高地开阔，泽地积水为分散水洼而非持续淹水。阶段 3 据此将两群系加入 `data/starrail_sim/tags/worldgen/biome/the_path_regions.json`。普通浮空遗迹引用该标签；遗器决斗场的 `relic_trial_arena_spawnable` 又引用 `the_path_regions`，所以两种结构都将获得在两个新群系生成的资格。没有修改结构蓝图、奖励或间距算法。

这项标签选择是基于阶段 0 地貌样本作出的首轮实现判断。离线采样不能证明结构实际可达；测试世界中仍须观察浮空遗迹高度、决斗场的 25×25 地面清理/支撑范围，以及芦苇、浅水洼和高地坡面附近的落点。若泽地场地破坏生态或任一结构难以到达，应收窄专用生成资格，而非改结构蓝图。
