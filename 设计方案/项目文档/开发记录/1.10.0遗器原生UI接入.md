# 1.10.0 遗器原生 UI 接入

日期：2026-10-10。

## 入口与布局

解禁角色界面原有的“遗器”栏目，在 `StarRailCharacterScreen` 内以 `StarRailRelicPanel` 组件实现。没有新增主界面或导航项目；详情、光锥、行迹、命途和指南均可切换至该栏目。

沿用已认可的六槽方案：外圈头部/手部在左上/右上，躯干/脚部在左下/右下；内圈位面球/连结绳在中央的左上/右下，所有槽框为圆形，没有中央人物。

## 已实现的界面框架

- 装备、强化、分解、合成、重掷五个功能标签。
- 名称搜索，部位/套装/星级/主属性/装备状态筛选，排序与锁定筛选。
- 遗器详情、主副属性、装备对比、贡献汇总、换装及消耗确认弹窗。
- 强化目标与三等级节点、前后结果比较；晶块/残骸分解模式；普通/定向合成与材料制作；变量骰子候选的新旧结果选择。
- 外圈及内圈反向待机流光、小圆框呼吸与旋转、图标浮动、悬停反馈、点击扩散环、操作结果光效、平滑滚动。
- 切换遗器只重建控件，不重建组件，不重置待机时间；也不会重复缩放界面的逻辑坐标。
- 中英文界面文案；独立库存及详情滚动区域。

## 数据边界

普通模式显示空库存和功能待接入提示。开发环境可点击“开启界面预览”，使用独立的临时库存及材料演示操作；关闭界面后不写入存档，不修改玩家装备、背包、属性或真实材料。

`StarRailRelicUiData` 定义快照与操作接口；预览实现为 `StarRailRelicPreviewData`。套装效果继续标记待定，成长值及材料消耗沿用界面演示，不将尚待核对的数值提案应用为正式规则。真实服务端校验、物品、Curios 六槽、存档和同步留到遗器系统阶段接入。

## 遗器属性汇总与套装战斗效果（2026-10-11）

- 新增服务器端遗器汇总服务：登录、重生、维度切换和六个遗器Curios槽变更时，重新读取物品NBT并汇总主副属性。通过固定UUID的临时属性修正叠加到生命、攻击、护甲、护甲韧性及本mod自定义属性，不改写玩家基值；百分比先按遗器总值相加，再应用为一个修正。
- 接入确认的二件套常驻效果：过客治疗效果+15%、快枪手攻击+12%、圣骑护甲+15%、太空站攻击+24%、仙舟最大生命+20%。套装件数从服务端装备栏重算并缓存，用于战斗触发，不依赖客户端预览数据。
- 接入确认的四件套效果：快枪手所有玩家来源伤害+10%；过客击杀敌对类别目标后，治疗自身及10格内玩家，基于装备者最大生命的5%；圣骑使本mod生成的伤害吸收量提高20%，覆盖丰饶、存护与同谐的护盾授予路径。
