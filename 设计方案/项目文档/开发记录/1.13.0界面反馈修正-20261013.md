# 1.13.0 界面反馈修正

日期：2026-10-13

## 根据截图修正

- 遗器装备页的四个配装预设按钮与六槽环形示意重叠。将环形示意和六个槽位整体下移22个界面逻辑像素，给预设按钮留出独立的顶部空间。
- 遗器试炼台原先将五套目标套装同时显示为卡片。改成单一的当前套装按钮，点击后展开五项纵向列表；列表支持点击选择和按Esc关闭，仍通过现有菜单按钮由服务端保存所选套装。
- 共用按钮悬停缓动由0.065秒调整到0.16秒；点击水波由0.5秒延长到0.78秒，并增加短暂的边框光晕与底部扫光。
- 关闭按钮和行迹节点补充点击脉冲；显示预览页的示例按钮也放缓悬停与按下回弹。
- 遗器槽、库存卡片和展开选择列表增加缓入缓出的悬停反馈，槽位图标随悬停平滑抬升，切换、选中和反馈光点延长。
- 减少动效设置仍会关闭点击水波、光晕和待机动画。
- 将思源黑体的来源说明和 OFL 许可证从 `assets/starrail_sim/font` 移至 `META-INF/licenses/starrail_sim/source-han-sans`；字体资源目录现在只保留字体定义 JSON 与 OTF，避免资源扫描把说明文档识别为无效资源路径，同时随模组资源保留授权文本。
- 六个遗器槽位的短提示改为锚定在对应圆环边缘绘制，避免头部、手部等外圈按钮的悬浮提示因界面缩放而漂离槽位；库存遗器卡仍显示完整物品提示。
