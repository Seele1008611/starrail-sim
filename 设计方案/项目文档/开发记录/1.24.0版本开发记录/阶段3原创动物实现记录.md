# 1.24.0 阶段 3：原创环境生物和自然生成

日期：2026-10-27。状态：**阶段 3 实现与用户实机验收已完成；阶段 2 已由用户验收通过，未改动阶段 2 作物或植物实现。**

## 本阶段目标

在命途遗境四个陆地群系中，以五种原创实体替代猪、牛、羊、鸡和马的后续自然生成；保留对应生存用途，新增与物种行为相符的动作，并接入阶段 2 已准备的肉类。

## 已确认设计

- 晴穗角鹿：晴穹草甸为主，星辉林地少量出现；保留奶桶互动和繁殖，掉落晴穗肉及少量皮革。
- 星绒岩羊：星砾高地为主；保留剪毛和羊毛，掉落独有的星绒羊肉。
- 林息觅食兽：星辉林地、静潮泽地；仅以林息豆荚或星薯繁殖，掉落林泽肉。
- 泽纹羽禽：草甸、林地、湿地；保留下蛋、种子繁殖，掉落泽纹禽肉和羽毛。
- 星砾驮兽：草甸少量出现并可在高地出现；保留驯服、骑乘、配种，不掉肉。
- 不改已生成区块内的原版家畜；不改主世界、海岸、海洋及洞窟的原版生物生成。
- 专属动作按阶段 0 决议实施：角鹿取食警戒、岩羊短跃攀行、觅食兽拱地、羽禽啄食振翅、驮兽多步态与起跳。

## 当前进度

- 五种实体类和独立实体类型注册表已新增，保留各自原版互动基础；觅食兽繁殖物品已限制为林息豆荚和星薯，驮兽仅与同类配种。
- 主模组入口已接入实体注册、属性、地面生成规则和客户端渲染器；实体使用独立注册 ID，原版实体的既有区块不会被转换。
- 四个命途陆地群系的 `creature` 表已改为新实体。权重与群组范围按体型和稀有度降低；浅水岸生成限制仍需实机确认。
- 五种实体的独立 loot table 已新增；角鹿、岩羊、觅食兽、羽禽和驮兽分别使用阶段 2 的三种肉类与原版副产物。
- 五份 Blockbench 原型已转换为逐面 UV 运行时模型和五张实体纹理；实体尺寸通过独立缩放适配原始模型坐标。
- 已加入五种不同动作：角鹿取食与警戒、岩羊短跃和剪毛反应、觅食兽拱地、羽禽啄食与振翅、驮兽步态和跳跃姿势；觅食/警戒状态由服务端同步。
- 名称、刷怪蛋模型与创造栏入口已接入。阶段 3 相关 16 个 JSON 文件通过解析，五张实体纹理均存在。
- 使用项目已有 Gradle 8.8、Java 17 和 `--offline` 执行 `compileJava` 成功；保留项目中已有弃用 API 警告。本次没有运行自动化测试或下载依赖。
- 阶段 2 已由用户实机验收通过；本阶段未修改星薯、静潮稻、阶段 2 食物或生态植物实现。
- 用户启动首轮阶段 3 测试包时，游戏在物品注册事件中因读取尚未注册的 `sunnyharvest_deer` 实体而崩溃。刷怪蛋工厂原先在 `ITEMS.register` 的 Supplier 内立即调用 `RegistryObject.get()`；现改用 Forge 1.20.1 的 `ForgeSpawnEggItem` 延迟持有实体 Supplier，避免注册顺序依赖。
- 用户首轮实机测试发现五种自然生成动物都显得过小且上下颠倒；五种实体原先仍沿用原版叫声；岩羊掉落原版羊肉。已修复 LivingEntityRenderer 的原版坐标翻转与方体模型 Y-up 坐标不一致问题，并按模型高度调整渲染缩放。第二轮反馈后又同步扩大角鹿、羽禽和驮兽的实体碰撞箱与模型尺寸。
- 上一轮曾为五种动物各加入 ambient、hurt、death 三种程序合成音效；用户试听后认为有电子合成感。本轮删除这 15 个合成 OGG 和生成脚本，保留模组自己的声音事件 ID，改为引用 Minecraft 内置动物录音：角鹿用山羊、岩羊用羊、觅食兽用猪、羽禽用鸡、驮兽用羊驼的环境/受伤/死亡音效。
- 岩羊覆盖原版羊按毛色选择掉落表的逻辑，改为读取自身实体掉落表；首轮修复暂时使用晴穗肉，后续按用户意见改为星绒羊肉与对应烤肉。
- 上一轮修复包（无羊肉专属物品）已由下方更新包替代；此前阶段记录中的大小与哈希仅指向该历史构建，不再作为当前测试包校验值。
- 用户认为岩羊应有专属肉类，新增星绒羊肉与烤星绒羊肉两件物品，生/熟营养值按原版羊肉定位为 2 / 0.3 和 6 / 0.8；岩羊普通击杀掉生肉、着火击杀掉熟肉，并提供熔炉、烟熏炉和营火配方。两张原稿放在 `崩铁/物品/食物与种子`，运行贴图为 16×16；阶段 2 的晴穗肉、林泽肉、泽纹禽肉内容不变。
- 用户第二轮实机反馈包括岩羊眼睛不明显、头部附件不随头转、动物叫声电子感、四种非岩羊贴图太花、角鹿/羽禽/驮兽体型偏小、羽禽不能使用新增种子繁殖、全部新增动物不跟随繁殖食物、驮兽鞍具不可见。本轮已逐项修复：岩羊面部 UV 眼睛加大；耳、角、喙、冠饰统一继承头部旋转；四张非岩羊运行贴图降低高频噪点并保护正面五官 UV；角鹿、羽禽、驮兽模型与碰撞箱同步放大；羽禽繁殖与跟随同时支持四种 1.20.1 原版种子和项目三种种子；五种动物均增加对应繁殖食物跟随目标；驮兽按鞍具状态渲染鞍垫、鞍座、侧翼和腹带。
- 2026-10-27 追加修正：五种新增动物的 ambient、hurt、death 三个事件现在都映射到同一条对应物种叫声 OGG。岩羊贴图前脸 UV 的双眼从纹理第 45–47 行移到第 49–51 行；模型渲染将该面 UV 的上方映射到几何体下方，原眼睛因此落在口鼻方块后被遮挡。运行时贴图和归档原稿同步更新。羽禽跟随与手喂繁殖现在共用 `starrail_sim:stilltide_fowl_breeding_food` 物品标签，包含四种原版种子、林息豆种、星薯种和静潮稻种；`TemptGoal` 与 `isFood` 均读取该标签，避免两套清单不一致。继续排查后发现鸡原版 `BreedGoal` 和新增 `TemptGoal` 同为优先级 2，会互相争抢移动目标；现将新增种子跟随目标设为优先级 4，使爱心状态下的繁殖目标优先运行。

## 历史复测清单（当前已验收）

用户于 2026-10-27 确认测试通过。以下条目保留测试范围记录，不再作为阶段 3 待办。
