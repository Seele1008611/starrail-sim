# 1.24.0 阶段 0：生态与战斗设计提案

日期：2026-10-25。状态：**用户已确认按本提案进入阶段 1；设计方向冻结，尚未进入代码实现或游戏内验收。**

本记录把已确认的 1.24.0 方向具体化为生态、食物和遗迹 Boss 方案。用户于 2026-10-25 确认按此方案继续；名称为工作名，配方数值、动画和战斗细节可在视觉原型及后续平衡中微调。

## 一、已确认范围

- 七个既有群系继续深化，不新增群系。
- 普通遗迹和九命途遗迹统一使用完全原创的遗迹监守者，以少量命途配置体现差异。
- 在命途遗境陆地群系中，以原创动物替换猪、牛、羊、鸡和马；允许改造复用原版模型基础。
- 为命途遗境建立自己的肉类来源，并增加数种可种植食物。
- 遗迹主题化换材不在 1.24.0 范围内。

## 二、源码基线

### 2.1 当前动物分布

当前地表生成表中，晴穹草甸和星砾高地生成猪、牛、羊、鸡、马；星辉林地和静潮泽地生成猪、牛、羊、鸡。澄沙海滩生成海龟；星潮海域生成鳕鱼、鲑鱼、鱿鱼和海豚；星脉洞窟没有环境类动物刷出表。

这意味着本版只需替换四个陆地群系里的家畜生成。海龟和海洋生物先保持；不把家畜塞进海滩、海洋或洞窟。

### 2.2 当前食物

| 内容 | 当前营养值 | 当前饱和度系数 | 备注 |
|---|---:|---:|---|
| 晨露莓 | 2 | 0.2 | 可重复采收 |
| 林息豆荚 | 3 | 0.3 | 可种植；可烧成熟食 |
| 烤林息豆 | 5 | 0.6 | 现有植物食物中较强 |
| 星潮藻 | 1 | 0.1 | 可重新种植 |
| 烤星潮藻 | 4 | 0.5 | 水下可持续食物 |

当前命途遗境的肉类来源来自原版动物掉落。新方案应替换生肉和熟肉掉落，但无需为追求“全部物品都原创”而重复制作皮革、羊毛、羽毛和蛋的基础用途。

### 2.3 遗迹守卫状态

`StarRailRuinGuardService` 当前以遗迹原点保存守卫 UUID、遗迹变体、是否击败、是否领奖、复战状态、召唤冷却和已开启门等状态；实体和击杀处理直接依赖 `Warden`。新实体需接入该状态流程，不能只改生成类型。

## 三、原创环境动物提案

以下工作名和生存用途用于讨论。建议保留原版动物有价值的互动习惯，同时让所有食用肉类都改为模组物品。皮革、羊毛、羽毛、鸡蛋等常见副产物暂建议沿用原版物品，减少无必要的配方断裂和物品数量。

| 工作名 | 对应原版角色 / 模型基础 | 主要栖息地 | 建议行为和用途 | 建议掉落 |
|---|---|---|---|---|
| 晴穗角鹿 | 牛 / 牛形体改造 | 晴穹草甸，星辉林地边缘 | 温和群居，可繁殖；建议保留装桶取奶的用途 | 晴穗生肉；熟制为晴穗熟肉；少量皮革 |
| 星绒岩羊 | 羊 / 羊形体改造 | 星砾高地，草甸边缘 | 适应坡地；可剪取羊毛，剪毛不伤害动物 | 星绒羊肉；沿用羊毛 |
| 林息觅食兽 | 猪 / 猪形体改造 | 星辉林地，静潮泽地 | 温和觅食，可繁殖；以林息豆荚或星薯为繁殖食物 | 林泽生肉与熟肉 |
| 泽纹羽禽 | 鸡 / 鸡形体改造 | 草甸、林地、湿地边缘 | 小群活动、产蛋、可繁殖 | 泽纹禽生肉与熟肉、羽毛、蛋 |
| 星砾驮兽 | 马 / 马形体改造 | 晴穹草甸、星砾高地 | 可驯服和骑乘，承接马的探索坐骑用途 | 皮革等非食用副产物；不以肉类鼓励击杀坐骑 |

### 3.1 群系分布建议

| 群系 | 建议出现的原创动物 | 分布意图 |
|---|---|---|
| 晴穹草甸 | 晴穗角鹿、泽纹羽禽；少量星砾驮兽 | 保持开阔草地有大中小型动物，坐骑较稀少 |
| 星辉林地 | 林息觅食兽、泽纹羽禽；较少晴穗角鹿 | 强调林下觅食和小型鸟群 |
| 星砾高地 | 星绒岩羊、星砾驮兽 | 以坡地适应型动物为主，控制密度保留视野 |
| 静潮泽地 | 林息觅食兽、泽纹羽禽 | 强调涉水觅食与岸边活动，避免生成在深水中 |
| 澄沙海滩 | 不加入家畜替代物；暂留海龟 | 海岸生态继续与湿地分开 |
| 星潮海域 | 暂留现有鱼类、鱿鱼、海豚 | 1.24.0 不重做水生动物 |
| 星脉洞窟 | 不生成上述五种家畜替代物 | 可用菌类和岩缝植被补生态；洞穴动物另作可选项，不与五种主动物强行合并 |

**刷出原则：**同一群系保留 2–3 种主动物即可，不照搬当前四种家畜几乎同时生成的做法。组群规模按动物体型和路径宽度调整；坐骑、角鹿低于普通觅食兽与禽类的出现频率。阶段 3 通过新世界实测调整权重。

### 3.2 肉类与副产物建议

建议新增四类肉，每类有生、熟两种物品：

| 食物线 | 来源 | 初稿营养值 | 设计目的 |
|---|---|---|---|
| 晴穗肉 / 烤晴穗肉 | 晴穗角鹿 | 生肉 3 / 0.3；熟肉 7 / 0.8 | 草甸主要肉源 |
| 星绒羊肉 / 烤星绒羊肉 | 星绒岩羊 | 生肉 2 / 0.3；熟肉 6 / 0.8 | 高地专属肉源，数值参照羊肉 |
| 林泽肉 / 烤林泽肉 | 林息觅食兽 | 生肉 3 / 0.3；熟肉 7 / 0.8 | 林地、湿地稳定肉源 |
| 泽纹禽肉 / 烤泽纹禽肉 | 泽纹羽禽 | 生肉 2 / 0.3；熟肉 6 / 0.6 | 小型动物的补充肉源 |

营养值和饱和度是初稿：熟肉略高于烤林息豆，避免新食物压过探索作物；生肉接近原版生肉的用途。掉落数量参考成年动物体型并受抢夺附魔影响；坐骑不掉肉。原计划食物线的数值在阶段 0 冻结；星绒羊肉的新增数值以 2026-10-27 用户补充决策为准。

**2026-10-27 用户补充决策：**首轮实机测试后，用户认为岩羊掉落晴穗肉不够合理，决定给星绒岩羊增加独有的星绒羊肉及烤星绒羊肉。其数值按原版羊肉定位为生肉 2 / 0.3、熟肉 6 / 0.8。此项作为阶段 3 的新增掉落内容；阶段 2 已完成的三种肉类及其配方保持原样。

为了保持既有合成用途，建议保留原版皮革、羊毛、羽毛和蛋作为副产物；“掉落重做”的硬要求先聚焦所有肉类改成原创物品。若你希望副产物也全部原创，可在进入阶段 1 前扩展物品清单。

### 3.3 物种动作差异与动画要求（2026-10-26 补充）

用户补充要求：新增生物和怪物不能只有不同外观，必须有可辨认且符合物种/战斗用途的动作。通用站立、行走等基础动作可以共用或改造原版实现，但每种动物至少有一个专属动作表现；监守者的不同招式必须使用不同的蓄力、攻击和收势动作，不能只换伤害参数。

| 生物 | 专属动作方向（实现前可再细化） |
|---|---|
| 晴穗角鹿 | 低头取食，察觉威胁时抬头警戒并准备奔跑 |
| 星绒岩羊 | 山地短跃/稳步攀行；若保留剪毛互动，剪毛时有明显甩身或抖毛反应 |
| 林息觅食兽 | 低头嗅闻并拱动地面寻找食物 |
| 泽纹羽禽 | 啄食，受惊时短促振翅或扑跳 |
| 星砾驮兽 | 走、快步和奔跑有可区分的骑乘步态，并有起跳动作 |

动作差异应服务于已确认的行为和互动；不要求所有生物都制作庞大动作集，也不把姿势细节塞进建模三视图。阶段 3 为动物实现基础移动与专属动作；阶段 4 为监守者实现与招式相对应的动作序列。

## 四、可种植食物提案

计划新增三种食物植物，分别补高地、湿地和林地/洞窟。名称为工作名，营养值为提案。

| 工作名 | 适配群系 | 生长方式提案 | 种源与收获 | 食用方向提案 |
|---|---|---|---|---|
| 星薯 | 星砾高地 | 四阶段块根作物，种在耕地；成熟后可留种 | 高地自然小片生成，挖掘成熟植株有星薯并有机会回收种薯 | 生食 2 / 0.2；烤星薯 5 / 0.6 |
| 静潮稻 | 静潮泽地 | 八阶段谷物，种在湿润耕地，附近需有水 | 泽地水边自然生成少量野稻，成熟收谷粒和种子 | 谷粒可烹熟成泽米，约 5 / 0.6；避免强制做碗类料理 |
| 星辉菇 | 星辉林地、星脉洞窟 | 菌类放置在腐殖土/命途泥土等合适基质；低光、湿润处可扩繁 | 林下和洞穴缝隙生成小簇，采收后可扩繁 | 生食约 2 / 0.2，烹熟约 4 / 0.5；作为低成本补充食物 |

三种作物都需能从命途遗境的自然生成中获得初始种源，并可在玩家基地持续繁殖；不要求七个群系都出现新作物。营养数值应与现有晨露莓、林息豆和星潮藻区分。

## 五、其他群系生态补层提案

- **星砾高地：**把星薯野生植株和一种耐风低矮灌木作为主要新增地表生态；避免继续增加与星砾垫草功能相同的地被植物。
- **静潮泽地：**增加贴近水面的浮叶/根系小景，静潮稻只在浅水边缘生长；深水和路径不被植被封住。
- **星脉洞窟：**用星辉菇与洞壁菌簇填充少量岩缝；是否增加一只低干扰环境动物（如洞穴飞行动物）作为可选项，等评估实体工作量后决定。
- **草甸、林地、海岸和海洋：**优先用新的生物分布与现有内容组合出差异，避免为每个群系都新增一套方块。
- **声景与发现记录：**七个群系目前都使用 `minecraft:ambient.cave` 心情音。建议先做群系对照清单，只为辨识度最强的一两个群系准备声景变化；新增生物和作物在指南中提供生成和种植提示。

## 六、原创遗迹监守者提案

### 6.1 外形概念

工作概念名为**星脉构装守卫**：古代遗迹中的石质/金属构装体，以清晰可见的星核作为弱点和攻击蓄能点。轮廓保持方块化，主体由躯干、双臂、肩部碎片和核心光环组成；外形不沿用 Warden 的胸腔、触须和感声结构。Blockbench 原型阶段再决定具体比例与关节形式。

### 6.2 基础招式提案

| 招式工作名 | 动作与提示 | 玩家应对 |
|---|---|---|
| 星轨横斩 | 一侧手臂抬起并显著蓄光，随后向前方扇形横扫 | 向侧面闪避，贴身绕到背侧可避开主要范围 |
| 核心震波 | 核心向地面投下清晰圆形/环形标记，短暂延迟后释放震荡波 | 离开标记区或在波形到达时跳跃；攻击结束后留下短反击窗口 |
| 直线突进 | 锁定玩家方向，地面出现窄直线提示后向前冲撞 | 横向闪避；撞到墙体或冲刺结束时短暂失衡，可抓住破韧机会 |

招式先共享于所有遗迹版本，不为九命途各做一套 AI。基础版至少保留两种招式；第三种取决于动画和联机同步成本。破韧时增加清晰硬直窗口，不以不可读的连续伤害惩罚玩家。

### 6.3 命途差异配置提案

建议配置只调整属性、招式参数和一种轻量表现，不增加独立招式树。可先采用三个战斗轮廓：

| 轮廓工作名 | 暂定命途归类 | 差异方向 |
|---|---|---|
| 强袭 | 巡猎、毁灭、欢愉 | 略快的追击/冲刺节奏，减少防御停顿 |
| 守御 | 存护、丰饶 | 略高韧性或防守间隔，攻击更容易预判 |
| 领域 | 智识、虚无、记忆、同谐 | 多用地面标记和范围控制，降低单次近战压迫 |

上述命途归类只是方案。若更适合现有 Path 设定，可只保留共同 Boss 和每条命途的少量生命/伤害参数，不强求三种 AI 轮廓。普通遗迹使用基准配置。

**战斗流程：**远距离感知并靠近 → 选择带前摇的招式 → 招式结束进入短恢复 → 玩家持续攻击削韧 → 破韧后出现显著反击窗口 → 恢复攻击。所有伤害、冷却、死亡、掉落和状态变化由服务端控制。

### 6.4 奖励与存档边界

- 保留首次击败解锁宝箱、命途遗迹奖励、钥印重复挑战和 30 秒冷却；普通遗迹与命途遗迹的材料掉落仍分开处理。
- 旧世界只迁移 `StarRailRuinGuardService` 已登记、且遗迹原点与实体持久数据匹配的旧 Warden；保留 `Defeated`、`Rewarded`、召唤冷却、变体和门状态。不触碰任意自然生成 Warden。
- 已生成区块中的原版猪牛羊鸡马建议保留，不自动删除或转换，以免丢失玩家驯养、命名和繁殖进度；升级后只停止它们在命途遗境中的新自然刷出。

## 七、阶段 0 建议验收清单

以下阶段 0 决策已由用户确认，阶段 0 标记完成：

1. 五种动物的工作名、模型基础、群系分布及主要互动方式确认。
2. 原版家畜关键用途的保留范围确认；特别是角鹿挤奶、岩羊剪毛和驮兽骑乘。
3. 三类生肉/熟肉、掉落范围和最终营养值确认；确认皮革、羊毛、羽毛和蛋是否沿用原版物品。
4. 星薯、静潮稻、星辉菇是否作为三种新增可种植食物，以及其种源、生长方式和烹饪路径确认。
5. 星脉构装守卫的视觉方向、基础招式数量和三个命途轮廓的归类确认。
6. 旧世界只保留已有家畜、只转换遗迹绑定 Warden 的迁移策略确认。
7. 决定洞窟环境动物、群系声景和发现记录是核心还是可选增强项；不因此扩展为新群系或遗迹主题化换材。
8. 用户补充确认：五种原创动物和原创监守者都要有区别于其他种类的动作表现；具体动作按物种用途和 Boss 招式落入阶段 3、阶段 4 实现。
