# 1.23.0 阶段 0：生态内容基线

日期：2026-10-23。阶段 0 原型已由用户实机验收通过，高地低矮植物正式纳入版本。阶段 1–3 首轮代码、资源与世界生成配置已接入。首轮用户反馈修复后，用户确认贴图合格，但芦苇仍未自然出现并要求改为双格；当前修正版待离线打包和新区块复测。

## 内容与行为约定

| 内容 | 工作名 / 资源键 | 行为基线 | 自然生成 |
| --- | --- | --- | --- |
| 高地碎砾 | 星砾 / `path_ridge_scree` | 重力方块，可采集且默认掉落自身；铲子加快采集但不要求正确工具掉落；可用于地形建造，不产出新矿物或装备资源 | 仅在高地小片地表沉积；首轮放置特征尝试落在天穹岩、河床砾和坡地粗土上 |
| 泽地土壤 | 静潮腐殖土 / `path_marsh_humus` | 复用 `PathTillableSoilBlock`：锄成原版耕地、锹成土径，采集掉落自身；列入原版 `dirt` 方块标签 | 作为静潮低地浅层土壤；噪声表面规则在砂砾水边和陡坡处优先保留专用地表材料 |
| 湿生植物 | 静潮芦苇 / `path_marsh_reed` | 双格、窄形状、无碰撞但可选中的植物；可采集后重放。下半格的适生基底包括本项目土壤及原版泥土/黏土/泥块，且须水平邻水；不要求玩家处于原群系；不作食物、不随机生长或蔓延 | 仅在静潮泽地生成。首轮特征筛选腐殖土和四个水平相邻格中的水，不直接在水面或深水中铺设 |
| 高地低矮植物（用户已确认） | 星砾垫草 / `path_ridge_cushion` | 独立的矮小簇状植物，可采集后带回；允许在命途草方块、坡地粗土和星砾上重放；自然群系限制与人工种植基底限制分开；不作食物、不随机生长或蔓延 | 仅在星砾高地稀疏生成，保留岩面、地面与远景可读性 |

两种植物均不通过随机生长变高或自行蔓延；当前实现不响应骨粉。两者先按 0.3 堆肥概率注册为堆肥材料。这个低值遵循潮汐草等装饰植物的既有处理，不建立新的食物、成长或资源门槛。

首轮生成配置：高地碎砾每区块一次、随机尝试 6 个位置；垫草约每两区块生成一次，每次 6 个位置；芦苇首轮约每两区块生成一次，每次 6 个位置。用户反馈芦苇过于难以见到后，第二轮改为每区块 2 个锚点、每锚点 24 次岸线尝试；最终密度仍待新生成区块实机检查。

## 资产与代码接入位置

- 地表块注册：`PathTerrainBlocks.java`；可耕土沿用 `PathTillableSoilBlock`。
- 植物及其物品：`PathEcologyContent.java`，新植物根据基底/邻水要求使用独立方块实现；不要因复用海滩植物代码而意外继承其群系生存锁定。
- 每项资产需补全方块状态、方块/物品模型、掉落、采集标签、中英文显示名与适用指南。非完整模型显式指定粒子材质。
- 原图与最终游戏纹理遵循项目方块贴图规范；星砾、腐殖土、垫草为 16×16，双格芦苇为 16×32，并拆分为上下两个 16×16 方块贴图。原型阶段现有河床砾、林息腐殖土与草类只是占位。
- 阶段 0 地形原型有意替换两个候选群系的 `vegetal_decoration` 特征列表，以隔离观察地形、路由和表面材料；因此它不会保留草甸的晴穗树/花/晨露莓，也不会保留林地的流萤树/林息豆/苔藓等原有植被。原型画面不能据此冻结最终植被构成；高地低矮植物与泽地芦苇仍未实现。
- 两个新群系接入还涉及维度群系源、表面规则、configured/placed feature、探索记录、指南、定位、进度与生成群系标签。阶段 0 原型不扩展既有结构的生成标签；阶段 3 根据采样得到的开阔高地与散布浅水低地，将两个可步行陆地群系加入 `the_path_regions`。普通浮空遗迹与引用此标签的遗器决斗场因此均获生成资格；实际结构落点、地面清理和支撑仍待新世界检查。
