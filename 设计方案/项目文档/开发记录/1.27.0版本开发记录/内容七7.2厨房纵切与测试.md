# 内容七 7.2 厨房纵切与测试

test40 已完成离线构建，并核对测试 JAR 内的料理台、菜单、双语资源和 21 个配方文件。用户已确认游戏内测试通过，要求将前后箭头切换改为可展开的下拉菜单，并已提供食物原图，随 7.3 处理。

## 测试物资

在创造栏找料理台、料理锅、煎盘和下表原料，带一组煤炭。测试命途泉水时，带命途空瓶进入命途遗境，对水源方块右键取水。雪根、泽纹禽蛋、玉米粒和泉矿料本轮从创造栏获取，自然来源随生态阶段接入。

| 路线 | 工序 | 原料与预期 |
| --- | --- | --- |
| 雪原大乱炖 | 料理锅，炖煮 | 岩羊生肉、烤星薯、雪根、命途泉水、碗各一，出一份汤并返空瓶。生存食用后返碗，获得 60 秒细雪抗冻 |
| 大宇宙炒饭 | 煎盘，炒制 | 熟静潮稻、泽纹禽蛋、泽纹禽生肉、玉米粒、日籽油各一，出两份炒饭。日籽油由两份日籽用料理锅加工 |
| 霜莓派 | 煎盘，烘烤 | 霜莓、谷糖、泽纹禽蛋、谷粉各一，出一份霜莓派。谷粉可由玉米粒或熟静潮稻在工作台制作，谷糖用两份玉米粒在料理锅加工 |
| 熟静潮稻 | 料理锅，蒸制 | 静潮稻谷和命途泉水各一，出一份熟静潮稻并返空瓶 |
| 苏打豆汁儿 | 工作台 | 先用命途泉水和泉矿料合成起泡水，再和林息豆荚、谷糖合成苏打豆汁儿。生存喝完返命途空瓶 |

## 结算与存档

1. 在料理台用箭头选配方，放入原料、燃料和对应厨具，再点开始。比对成品数量、返还物以及厨具留存情况。
2. 用一根木棍为一锅汤提供燃料，等进度因燃料耗尽暂停，退出并重进存档，补煤后应从原进度继续。用另一批原料重复操作，确认每批只结算一次。
3. 加工中取走一项原料，确认任务取消。把上批不同的成品留在成品槽，启动新配方，确认取出旧成品前新配方暂停。
4. 在生存模式食用汤和冷饮，检查返还容器。食用汤后站进细雪，确认抗冻期内不会累积冻结，并在效果到期后复查。

测试包位于 `libs/starrail_sim-1.27.0-test40-kitchen.jar`。
