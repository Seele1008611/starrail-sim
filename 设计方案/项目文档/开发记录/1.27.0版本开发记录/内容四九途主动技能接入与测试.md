## 玩法与现有系统的接口

- `ExtraActivePathSkills`负责有限生命周期的施放会话；每位玩家只保留当前命途的一次会话。切途/降级/死亡/离线/跨维度清会话和该来源的同谐增益，CD仍按既有持久化剩余tick保存。
- 同谐各来源存入独立授予表，共用两枚专属修饰符UUID；只要仍有一个合法来源就保留一份12%/15%，不叠加。来源失效、接受者死亡/离线/跨维度或双方不再同队时撤销对应授予。接受其他同谐玩家的增益，不因自己切到另一命途而误清。
- `LivingDamageEvent`最后阶段只记录有效直接攻击；已存在的二次伤害保护排除附伤/DoT。欢愉附伤排至本tick末，避免在原伤害事件内嵌套改写其结果。
- 新增数据驱动伤害类型`starrail_sim:active_skill`及追加式`bypasses_cooldown`标签，让独立附伤不被原攻击的受击间隔吞掉；**未加入穿护甲、穿抗性或穿无敌标签**，归属仍为施放玩家。
- 主动伤害作用域增加独立标志，阻止主动杀伤再触发侵蚀死亡扩散；真实击杀仍走原奖励规则，未凭空加层/加践行度。虚无明确成功授予的既有侵蚀与迟缓按原生命周期结束，取消场地后不再新施加；不会删除后来由普通攻击或别人授予的负面效果。
- 生命莲华通过原`heal`事件，保留已有再生/溢出规则；实际敌伤凭据与成长奖励沿用既有口径，不编造“施放即获得奖励”，队友接受治疗的既有归属规则也未另写。
- 指南和命途页面读同一组技能参数；HUD增加剩余窗口、欢愉剩余击数、记忆记录量。`/starrailskill status`可审查窗口、记录量及收到的同谐来源/剩余tick。属性详情、遗器和原玩家状态HUD统计算法不改。

## 测试步骤

使用test12替换旧本模组JAR，只保留一个版本。统一R键，5级解锁；本次优先验证新增七途，也回归巡猎/存护。现有调试命令：

```mcfunction
/starrail path debug set destruction
/starrail path debug set_rank 5
/starrailskill status
```

将`destruction`依次换为`erudition`、`harmony`、`nihility`、`abundance`、`remembrance`、`elation`。需要敌人时可在测试场地召唤高血无AI尸壳：

```mcfunction
/summon minecraft:husk ~ ~ ~3 {NoAI:1b,Attributes:[{Name:"minecraft:generic.max_health",Base:1000.0d}],Health:1000.0f}
```

1. 毁灭：附近有敌人时按R，观察生命代价、范围伤害/特效；附近无敌人时不扣HP/CD；低血时不被代价杀死或抬高生命。
2. 智识：瞄准12格内地面按R，观察0.6秒预警与落下打击；用可移动敌人或自己走位观察区域位置固定、遮挡有效。
3. 同谐：按R前后用`/attribute @s minecraft:generic.attack_damage get`及移动速度查询比较，8秒到期撤销。单人可测试自己；有多人环境时同队两名同谐错开施放，检查只叠一份且较早来源到期不清晚来源。
4. 虚无：瞄准敌人脚下地面，观察第2/4/6秒三次脉冲；原已有侵蚀不反复刷新；离开区域不受新场地伤害，切途/跨维度取消区域。
5. 丰饶：先受伤再按R，观察即时恢复与后3次恢复；满血溢出沿用原规则。有同队玩家时检查施放范围，后续离远/隔墙/退队不继续接受治疗。
6. 记忆：准星锁定敌人按R，5秒内正常攻击几次，用HUD或指令看记录增长；结束出现一次回响。只用主动/DoT不增长记录；敌人提前死、卸载或结算时隔墙/远离不会在别处凭空打击。
7. 欢愉：按R后打出3次正常命中，查看剩余次数从3降到0及第三次范围爆发；空挥不扣次数，一次横扫多个敌人不能瞬间耗光；附伤确实生效而非被原伤害间隔吞掉。
8. 共同回归：4级不可用、5/6/7级可用；切途、死亡、重登、跨维度不刷CD。技能进行中切途，场地/治疗/记录/连击窗口停止，已有其他来源属性或黄心不被误清。
9. P界面检查九途说明与R键/HUD，原属性详情和遗器统计保持原逻辑；基础/增强、低粒子档、多人叠加和切维度无残留。无法测试的环境如实留待后测。
