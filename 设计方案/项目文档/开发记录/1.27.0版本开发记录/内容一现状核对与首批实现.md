## 26类事件基线

事件定义见 `CombatVfxPacket.Kind`，服务端确认入口为 `StarRailCombatVfx`，客户端由 `StarRailCombatClientEffects` 分发网格和声音，`StarRailCombatMesh` 按命途编排，`StarRailCombatShaders` 与 `StarRailCombatPost` 提供材质及增强合成。现有事件最多存活50 tick，48格外拒收，粒子最少档与其他档分别限制12/24个并发事件；这些是代码限额，不是本轮性能实测结果。

| 对象 | 当前事件（共26类） | 服务端来源与深化方向 |
|---|---|---|
| 巡猎 | HUNT_STRIKE、HUNT_REVERSE | CombatEvents → CombatVfx.queue/confirmDamage；四箭/八箭、中央终结箭。先做星弓与实际飞行光带，逆时追猎加入逆转刻度 |
| 存护 | PRESERVATION_WALL、PRESERVATION_COUNTER | PreservationService、PathEvents；保留盾面/盾阵和反震，后续研究盾片分层展开、承击波沿盾面传播 |
| 毁灭 | DESTRUCTION_RAGE、DESTRUCTION_BURN、DESTRUCTION_DESPERATE | DestructionService、CombatEvents；保留怒意/裂火，深化燃烧裂缝、上升火冠和爆发时的空间撕裂 |
| 智识 | ERUDITION_ECHO、ERUDITION_FINAL | EruditionService；实际追加目标逐一发送，后续设计演算矩阵展开、扫描线收束与终局阵列 |
| 虚无 | NIHILITY_MARK、NIHILITY_SPREAD、NIHILITY_END | DebuffService；标记/扩散/终结分别发送，后续以侵蚀链、内吸碎片及终结塌缩区别三阶段 |
| 同谐 | HARMONY_RESONANCE、HARMONY_AFTERGLOW、HARMONY_CONCERT、HARMONY_UNISON | HarmonyService、CombatEvents；后续设计乐谱光带、节拍节点、击杀回流与强化合奏 |
| 丰饶 | ABUNDANCE_HEAL、ABUNDANCE_MANNA、ABUNDANCE_MERCY | AbundanceService；后续深化枝叶生长、晶片折射、莲瓣展开与生命流回收 |
| 记忆 | REMEMBRANCE_RECORD、REMEMBRANCE_ECHO、REMEMBRANCE_ETERNAL | PathEvents；后续设计晶片记录、折返残像和强化两拍重映 |
| 欢愉 | ELATION_BURST、ELATION_GRAND | PathEvents；后续设计卡片翻转、面具裂光及错拍二次爆发 |
| 韧性 | TOUGHNESS_HIT、TOUGHNESS_BREAK | CombatEvents → CombatVfx.queue/confirmDamage；保持受击轻量，击破可深化破壳与碎晶散开 |

## 首批巡猎原型

1. 外围箭的发射位置出现短暂的弓臂和被拉开的弦，保留普通四箭、强化八箭及既有发射顺序。
2. 按箭当前二次曲线飞行进度回采样历史位置，绘制渐细、淡出的双光带；第二层绕飞行轴旋转，不是固定挂在箭后的直线。最少粒子档使用5段，其余档9段；普通历史长度0.13秒、中央箭0.19秒。
3. 强化中央箭落下前显示分段逆转刻度，命中后刻度反转收缩，碎光回卷；普通追猎不显示该刻度。使用既有世界锚点、深度测试、战斗材质及泛光管线，没有新加全屏pass。
4. 静态核对发现分类遗漏：HuntService当前返回普通2.0、逆时4.0，CombatVfx仍按旧1.5阈值选择视觉，导致普通追猎被归成强化。现将强化视觉阈值改为4.0；仅修视觉类型，不更改伤害或消耗/冷却。

相关源码：`src/main/java/com/starrail/sim/client/StarRailCombatMesh.java`、`src/main/java/com/starrail/sim/StarRailCombatVfx.java`。

## 武器/工具轨迹执行初案

- 六系列各5件加虚质裂界刃，共31件，后续实施逐一核对注册。剑使用锐利弧带，镐使用工具尖端的细长划迹，斧使用较厚、较短的切入弧，铲使用较宽但淡的扫迹，锄使用短钩形轨迹；轨迹由实际头部位置采样，不用静态图案假装运动。
- 配色从各系列当前贴图取样；不凭旧文档猜星琼色系。虚质裂界刃可增加破碎的紫色双层边缘。
- 挥动与命中分开：空挥仅轨迹，服务端确认命中/破坏后才有相应反馈。采掘连续动作限频；右键翻土/剥皮等仅成功时反馈。
- 初始尾迹存活预算0.12–0.18秒，按物品种类微调；采样应按时间/距离限量，低帧率细分有上限。传送、手持物变化、结束动作和维度变化断开采样，避免远距离拉线。
- 第一/第三人称与主副手分别核对真实物品变换；目前未接入手持物渲染采样，不声称这些锚点已验证。后续先做一个工具类别打通再覆盖全部31件。

## 第二轮巡猎深化（当前测试包）

用户反馈首版效果不错但仍可深化，并再次允许综合运用已总结的效果类型、发挥想象力。首版有正面反馈，不记为最终验收通过。

第二轮将不同表现层编排到同一视觉时间轴：

- 程序化网格：外围星座穹顶连结星点，中央箭发射前晶片孔逐片展开；终结箭带中空光束外壳，目标仍可见。
- 轨迹与运动：延续首轮双光带；强化命中后增加向上回卷的空心箭影。有限数量的碎晶按确定性弹道飞散，强化版沿原弹道返回，普通版正常消散；只是客户端几何运动，不生成物理实体。
- 材质与泛光：巡猎材质增加箭脊亮线和沿边缘流动的箭纹，继续使用已有HDR泛光。
- 局部后处理：发射孔周围出现收束折射，强化命中后出现反向旋扭与少量色散。使用现有深度门控、世界锚点、强度控制和四事件后处理上限，没有增加全屏pass或动态光照。
- 普通/强化共用主体，强化增加逆转与回收语义；动作仍属于已确认命中后的视觉演出，伤害不随特效时间重新结算。
