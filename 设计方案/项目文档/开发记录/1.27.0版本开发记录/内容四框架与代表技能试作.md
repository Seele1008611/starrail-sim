## 已接入的玩法

- 当前命途5级解锁，R键统一施放、可改键；只接入巡猎和存护，其余七途显示“本试作尚未接入此技能”。5级原有被动保留，不因新增主动删除。
- **巡猎·穿星一矢**：服务端准星射线寻找18格内第一个合法可见敌对生物，伤害为施放时攻击属性×2.2，冷却18秒。实体前的方块截断射线，并复核视线；同队、无关动物、无仇恨中立生物排除。本轮不提供主动PvP伤害。没有目标/等级不足不扣CD；合法施放而被免疫不返还CD。
- 主动伤害使用玩家归属的物理攻击伤害源，护甲与减伤照常生效；在`StarRailOwnedDamage`二次伤害保护作用域内执行，跳过追猎/暴击/光锥附伤等直接攻击入口，不消耗猎意、不额外套用一次属性倍率。真实死亡仍可走既有击杀记账及其奖励间隔，未手工授予猎意或践行度。
- **存护·守望壁垒**：最大生命20%+护甲×0.5，按现有护盾效果加成修正一次；持续8秒，冷却25秒。使用独立技能盾池，新增HUD单列余额和时间，**不写原版黄心**。
- 护盾顺序的4.1决定：原有护甲/减伤及黄心先结算，技能盾抵挡余下生命伤害（`LivingDamageEvent`最高优先级），后续健康损失/紧急治疗监听看到的是剩余伤害。到期、切途、降到5级以下、死亡、离线或切维度只清技能池，不扣任何原有黄心。绕过无敌的伤害不被技能盾拦截。该顺序替代草案的“建议主动盾先消耗”，理由是保留旧黄心多来源记账，避免重复扣除或误清。

## 框架和客户端

- `ActivePathSkills`在服务端检查当前命途/等级、存活、冷却、目标与视线；客户端请求没有可伪造的命途、目标、伤害或CD字段。按下边沿触发，长按不重复，聊天/菜单/失焦不施放；服务端还有5tick请求节流。
- 各命途独立剩余tick写入玩家持久NBT`starrail_active_skills.cooldowns`，仅在线tick递减。切命途不清，死亡Clone只复制CD，不复制临时盾；重登不减离线时间，切维度不刷新。登录/重生/跨维度与正常周期同步当前状态。
- C2S请求、S2C状态和S2C视觉三种新包，协议20→21；多人双方须同版。视觉包带维度、服务器tick、实际起终点和成功命中标志，拒绝过期/错维度/非有限/超距数据。
- HUD右下显示当前技能、真实绑定键和就绪/剩余CD，窄屏移到下半部避让原状态栏；F8沿用现有HUD开关。存护另列主动盾，不冒充黄心。冷却本地逐tick显示、服务器每秒与关键事件校正。
- 指南/命途页面新增两个技能说明，参数来自`ActivePathSkills`同一处定义。**没有修改属性详情、遗器、原HUD统计逻辑**。
- 视觉复用已有材质1/2与HDR泛光：巡猎瞬时青蓝星矢、命中碎芒；存护金色分片护壁展开。第一人称共线轨迹提供垂直方向回退，防止截面退化消失。效果有事件上限和一秒生命周期、世界切换清理，进入现有总面片预算。
- 新增只读`/starrailskill status`，输出当前命途、等级、CD tick、技能盾余额/剩余tick及各途CD。未新增绕过判定的免费施放或清CD指令。

## 测试步骤

替换旧JAR，仅留test11本模组。先在测试存档使用现有调试命令：

```mcfunction
/starrail path debug set hunt
/starrail path debug set_rank 4
```

1. 按R应提示5级解锁，不产生技能或CD。再执行`/starrail path debug set_rank 5`，应显示穿星一矢就绪。
2. 召唤高血、无AI敌人：

```mcfunction
/summon minecraft:husk ~ ~ ~10 {NoAI:1b,Attributes:[{Name:"minecraft:generic.max_health",Base:1000.0d}],Health:1000.0f}
```

   瞄准按R，确认星矢、伤害和18秒CD；移开准星/隔墙按R不产生新CD。按住R不连发。可用`/attribute @s minecraft:generic.attack_damage get`与敌人`Health`对照实际减伤后的结果；主动不吃猎意终结倍率，已有猎意不因这次伤害被消耗。
3. 切存护：`/starrail path debug set preservation`，再`/starrail path debug set_rank 5`；R获得独立护盾提示，8秒到期、25秒CD。原来黄心应保持原值，护盾不是额外黄心。
4. 被怪物攻击或用`/damage @s 10 minecraft:magic`测试。注意先消耗已有黄心，之后主动盾余额才下降；主动盾耗尽后生命照常减少。到期/切命途不能把其他黄心清空。
5. `/starrailskill status`检查两个命途独立CD。施放后切另一途再切回、死亡重生、退出重进、跨维度，均不可把CD刷成就绪；退出期间CD暂停递减，临时盾不保留。
6. 4/5/6/7级、第一/第三人称、改键、聊天/背包/失焦、F8隐藏提示，以及基础/增强渲染模式各检查一次。原属性和遗器统计应保持现有逻辑。

两个代表技能获认可后进入4.4其余七途；本次未接入其他七个技能。
