## 实现内容

主体与既有命途动作继续由 `StarRailCombatMesh.Scene` 编排，原中间层替换为八个独立深化方法。效果复用现有世界坐标、事件年龄、材质与后处理管线；不增加伤害结算、实体、掉落或玩法状态，不新增依赖。

| 命途 | 程序化造型与运动 | 材质及空间反馈 |
|---|---|---|
| 存护 | 分片展开六边盾格，盾面向上扫描；反震时盾格回弹，三层折面沿来源至目标推出 | 盾格接缝亮纹、六角方向折射与局部亮边 |
| 毁灭 | 怒意以少量上升火屑表现；燃烧展开裂火尖片，强爆发增加撕裂火翼和弹道火屑 | 高对比炽热裂纹、增强局部热流切向扰动；濒危自触发与目标爆发分别使用既有释放时点 |
| 智识 | 多平面演算网格、移动节点和扫描薄片；求解后阵列收束；来源至实际追加目标有传输光点 | 电路流动、扫描区域细格高光，与既有追加/终局两拍对应 |
| 虚无 | 暗色裂片组成侵蚀涡流，终结先收束再释放；扩散时光结沿真实来源连线抵达目标 | 暗核亮裂纹、内吸/外散的反向旋扭，标记、扩散、终结保留各自语义 |
| 同谐 | 环绕乐谱与跳动音符，强化增加弦线和节拍；余辉沿攻击方向传递，击杀回响从来源返回玩家 | 泛音亮纹、局部声波振荡，与三拍/强化合奏对应 |
| 丰饶 | 枝茎生长、成对展开叶片与回收生命光点；甘露为晶片端点，慈航增加拱形生命流 | 分枝叶脉、柔和纵向折射与微光，继续保留莲瓣绽放 |
| 记忆 | 晶镜绕枢轴翻转，记录后出现砂晶流；回响形成一次/强化两次外移镜框 | 冰晶棱面、六方向晶面折射与既有局部像素化 |
| 欢愉 | 卡片翻转、强化洗牌错拍，落地碎光以衰减弹跳轨迹运动；强化保留第二拍释放 | 卡面跳色、分条错位与色散，仍以粉金主题为主 |

这些小碎片是客户端网格运动，不作为世界物理实体；泛光与后处理不称为真实动态光照。沿用每场景6000面、全局48000面及12/24事件上限，部分节点/碎片随粒子档位减少。此处为代码限额，游戏帧率和实际同时触发观感尚未测量。

巡猎提前返回专属绘制分支，本批未修改其已通过的几何、材质分支或两种专用后处理样式。共用渲染仍需在测试包中回归观察。

## 测试方法

在已有Forge1.20.1实例替换旧JAR，确保模组只装一份。选择能看到地面、远景和墙面的场所；先用增强模式观察，再以基础模式对照。预览只播放视觉，不触发玩法伤害。

```text
/starrailvfx mode enhanced
```

逐个执行 `/starrailvfx preview <下表动作名>`，同一命途内普通与强化都看。不同命途间留出约3秒，之后再测试快速连续触发。

| 命途 | 动作名 | 重点 |
|---|---|---|
| 存护 | preservation_wall、preservation_counter | 盾格展开、承击收缩/反震光片、方向与角色是否清楚 |
| 毁灭 | destruction_rage、destruction_burn、destruction_desperate | 怒意轻量、燃烧与强爆发层次、裂火尖片与火翼 |
| 智识 | erudition_echo、erudition_final | 扫描网格、收束解算、追加光点和强化两拍 |
| 虚无 | nihility_mark、nihility_spread、nihility_end | 侵蚀片、来源传输、终结内吸再释放 |
| 同谐 | harmony_resonance、harmony_afterglow、harmony_concert、harmony_unison | 乐谱节拍、余辉传递、回流与强化合奏 |
| 丰饶 | abundance_heal、abundance_manna、abundance_mercy | 生长过程、甘露晶片、慈航莲瓣/生命流，是否遮挡角色 |
| 记忆 | remembrance_record、remembrance_echo、remembrance_eternal | 晶镜翻转、砂晶流、一次/两次镜框回响 |
| 欢愉 | elation_burst、elation_grand | 翻牌、强化洗牌与第二拍、弹跳碎光是否自然 |

最后回归 `hunt_strike`、`hunt_reverse`、`toughness_hit`、`toughness_break`。通过真实命途机制再触发一轮，观察移动目标、墙体遮挡、死亡目标与不同身高目标；预览中的模拟来源不能代替实战同步检查。

对照与回归：

```text
/starrailvfx mode basic
/starrailvfx preview erudition_final
/starrailvfx mode enhanced
/starrailvfx preview erudition_final
/starrailvfx status
```

检查第一/第三人称、粒子最少/减少/全部、暂停恢复、窗口变化与F3+T。关注效果是否锚定目标、是否遮挡视野、连续触发时是否串效或残留；同地点观察FPS与status网格构建耗时，但不以单一FPS数字宣称性能通过。
