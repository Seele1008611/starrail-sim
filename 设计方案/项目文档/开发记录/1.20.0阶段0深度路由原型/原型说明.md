# 1.20.0 阶段 0：垂直群系路由原型

这是一个用于隔离验证 biome depth 路由的数据包原型，不是正式模组资源。首轮实机确认后，路由和占位群系已作为阶段 1 起步配置复制到 `src/main/resources`；正式群系现沿用九种共享矿物和基础敌对生物表，尚未添加植物或地质特征。

## 当前假设

- 四个地表群系保留原有气候参数，各自有 `depth=0` 与 `depth=1` 两个选择点。
- 占位地下群系覆盖其他气候轴，`depth=[0.2,0.9]`。具体范围参考本地 Forge 1.20.1 原版 `OverworldBiomeBuilder` 的地下群系参数形式，只作为候选，不是最终数值。
- `depth` 是 biome source 的噪声参数，不可直接理解成 Y 坐标。该路由是否只落在洞穴空间、会否影响海底和地表，必须在游戏中新生成区块观察。

## 文件

- `data/starrail_sim/dimension/the_path.json`：保留现有维度类型和噪声设置，只替换 biome source 深度入口。
- `data/starrail_sim/worldgen/biome/starvein_cavern.json`：不含内容特征的临时占位群系。
- `pack.mcmeta`：1.20.1 数据包格式。

## 运行采样

如需重复首轮确认，可将本目录作为数据包放进一个全新的测试世界，再启用数据包创建世界。不要放进已有正式存档：维度地形配置只应用于新生成区块，旧区块不会重做。

首轮用户检查已确认地表下自然洞穴显示 `star` 开头的群系，海床下洞穴自然含水，其他观察未见异常。第二颗种子、各地表区域与洞口路线仍需阶段 1 回归。

本机没有 Minecraft 客户端控制工具；首轮客户端实机检查由用户完成。第二颗种子尚未复测。项目 `run/eula.txt` 仍为 `eula=false`，没有替用户接受服务端 EULA，也没有进行专用服务器采样。
