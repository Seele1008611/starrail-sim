# 1.4.0 UI 最终手动验收

状态：2026-10-06，玩家完成最终客户端 UI 手动验收并确认通过。本清单聚焦这次 UI 收尾；先前已通过的命途规则、遗迹、宝箱和服务端项目不重复验收。

## 准备

重启最新测试客户端，进入已有测试世界，打开角色界面。可使用已有装备与命途状态；本轮不需要新建存档。先在当前分辨率走一次交互，再改变窗口形状查看布局。

## 动效与交互

1. 鼠标移入、移出导航、命途卡片和分类标签：底色/描边渐变自然，选中态清楚。
2. 点击指南分类、命途卡片：点击反馈仅出现在操作的按钮，正文对应正确；左侧导航仍是圆点/线条动效。
3. 光锥拖动到两侧：原地旋转，左右各 30°；底光与反光跟随显示朝向。开关正面预览保留方向，从其他主页面重新进入恢复初始方向。
4. 四个长内容区滚轮、拖动滑块和点击轨道正常；属性行点击后的基础值、加成、最终值对应正确。
5. 切换主页面时星空相位连续；雾气保持分散、浅淡且缓慢漂移。地台弧线保持 60 秒一圈。

## 分辨率与 GUI 缩放

按实际显示器条件调整窗口；不要求超出屏幕范围，也无需每个窗口重复所有规则测试。

| 场景 | 示例尺寸或操作 | 检查内容 |
| --- | --- | --- |
| 当前常用窗口 | 当前分辨率 | 五个页面及两个弹窗布局正常 |
| 较小的 16:9 窗口 | 1280×720 或同比例缩小 | 标签、数值、卡片、关闭按钮无重叠或裁切，点击仍对齐 |
| 较高窗口 | 1024×768 或将窗口调近 4:3 | 内容上下留白合理，人物、光锥、列表在面板范围内 |
| 较宽窗口 | 可行时调近 21:9 | 内容不过度拉散，关闭按钮随内容区；星空填满背景 |
| GUI 缩放 | 设置中选两个可用档位，例如 2 和 3 | 渲染、按钮命中、滚动条拖动、弹窗关闭一致 |

改变窗口形状后重点打开详情、命途、指南及属性/光锥预览弹窗；检查长名称和最后一行能阅读，滚动条不粘住，关闭按钮可点击。
