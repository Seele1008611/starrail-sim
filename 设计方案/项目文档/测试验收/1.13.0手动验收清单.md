# 1.13.0 手动验收清单

本版功能已接入，以下步骤用于一次性游戏内验收。建议使用测试存档；遗器分解、背包满和切换全局字体等项目先保存世界。

## 验收结果

2026-10-13：用户确认本清单所列单人实机验收全部通过。多人游戏未测试。

## 1. 字体与显示设置

- [x] 打开指南中的“显示设置”，分别选择原版字体、仅模组界面使用思源黑体、全局默认文本使用思源黑体；切换后确认文字立即更新，重进世界后设置仍保留。
- [x] 全局模式下检查聊天、背包物品提示、书本或告示牌，以及模组界面；确认中文、英文、数字、粗体、斜体和物品图标字符可读。随后切回原版模式，确认界面恢复。
- [x] 切换普通／平滑绘制和完整／减少动效；检查设置立即生效，返回页面时按钮、圆环、选中框和字体没有错位。
- [x] 在100%、115%、130%、150%示例字号下查看预览页；确认圆中的数字居中、按钮字没有被裁切，连续点击时动效正常。
- [x] 在实际常用GUI缩放下查看角色详情、行迹、遗器和指南；检查线条、图标边缘、圆环保持平滑，遗器槽保持正圆。
- [x] 打开遗器装备页，确认右上方“开启界面预览”入口已隐藏，装备和库存操作仍可用。
- [x] 逐一悬停头部、手部、躯干、脚部、位面球和连结绳槽位；确认部位提示贴近对应圆环，库存卡悬浮时仍显示遗器详情。
- [x] 逐一悬停、点击导航、关闭、行迹节点、预设和普通操作按钮；确认光晕、扫光、水波持续时间适中，点击后页面仍立即响应。打开“减少动效”后确认动态效果停用。
- [x] 启动后查看日志，确认字体目录不再出现 `Invalid path in pack` 的 README／许可证警告。

## 2. 属性来源明细

- [x] 打开角色详情的属性详情，点击生命、攻击、护甲、护甲韧性、暴击率等属性行，确认弹窗能显示来源分类、修饰方式和最终值。
- [x] 改变一项来源（例如装备／卸下遗器或切换命途），再次打开明细，确认数值更新；关闭明细后能回到属性列表。
- [x] 检查较长来源名称和较多来源时的换行、滚动及返回操作。

## 3. 四套通用遗器预设

- [x] 装备一套可识别的六件遗器，保存到预设1；换成另一套后应用预设1，确认六个部位恢复为原物品且没有复制、消失或错位。
- [x] 保存第二套到预设2，在不同命途间切换后应用预设1和预设2，确认预设全命途共用。
- [x] 保存含空槽的配置并应用，确认空槽会按记录卸下；清空预设后确认该预设显示为空，不能误应用旧数据。
- [x] 保存后退出并重新进入世界，确认四套预设和遗器搭配仍在。
- [x] 将预设中的一件遗器卸下或分解，再尝试应用；确认界面提示缺件且当前六槽不发生部分变化。
- [x] 用测试物品填满背包后尝试切换到需要收纳当前遗器的预设；确认操作被拒绝，背包与装备槽都没有变化。完成后恢复测试物品。

## 4. 遗器试炼台再次挑战

- [x] 点击当前套装选择框，确认展开五套纵向列表；鼠标选择以及键盘上下键、回车均能切换套装，Esc可关闭列表。
- [x] 选择一个套装，完成三波挑战；结算后确认按钮变为“再次挑战”。
- [x] 再次点击，确认挑战重新开始，仍使用刚才选中的套装，波次与怪物数量正常。
