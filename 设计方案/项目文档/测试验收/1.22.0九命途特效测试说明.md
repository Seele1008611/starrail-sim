## 当前状态

九途均已接入专属动态网格材质和 HDR 泛光；各命途代表动作已加入对应的屏幕折射、扫描、像素化或节拍反馈。阶段 1 至 5 的单人实机测试均已通过，用户确认分层版自制音效效果合适。本说明继续作为 1.22.0 唯一测试说明；多人同步尚未测试。下方阶段 4 测试包信息仅用于追溯已通过的画质与渲染验收。

本包为 26 类特效加入了模组原创程序合成单声道 OGG 音效，按九命途区分音色与动作力度。相较第一版，冲击声增加了低频主体和清脆起音，共鸣类增加泛音与短反射，巡猎和虚无增加了气流拖尾；时长和主音色保持原方向。服务端确认的视觉事件包会在客户端同一落点播放对应音效；本机预览走相同播放入口。上一包 `stage5-audio.jar` 使用原版音源；`stage5-custom-audio.jar` 是上一版自制音效，可以与当前包直接对比。

## 阶段 5 音效验收

正式发行包使用与 `stage5-rich-audio.jar` 相同的玩法与音效资源。若需复核音效，可先与 `stage5-custom-audio.jar` 对比，再将“玩家”音量调至约 50%，逐个使用 `/starrailvfx preview <动作>`，确认每个动作都能听见与画面相配的短音效，并留意新增层次是否清晰、不过响、不拖沓；随后把“玩家”音量调为 0，确认音效停止但画面仍正常。再检查快速连续触发、同一攻击里的复合反馈、较远落点和切换基础/增强画面模式时的音量、距离与叠音情况。声音应跟随特效落点；同一路径的普通与强化动作能听出力度层级，多个反馈同时触发时不应刺耳或盖过画面。

预览指令对应表：`hunt_strike` 普通巡猎、`hunt_reverse` 强化巡猎；`preservation_wall`、`preservation_counter`；`destruction_rage`、`destruction_burn`、`destruction_desperate`；`erudition_echo`、`erudition_final`；`nihility_mark`、`nihility_spread`、`nihility_end`；`harmony_resonance`、`harmony_afterglow`、`harmony_concert`、`harmony_unison`；`abundance_heal`、`abundance_manna`、`abundance_mercy`；`remembrance_record`、`remembrance_echo`、`remembrance_eternal`；`elation_burst`、`elation_grand`；`toughness_hit`、`toughness_break`。视觉与音效都通过本地命令预览，不会触发战斗。

阶段 4 历史测试包不含触发音效，不能用它判断阶段 5 音效功能。多人音效同步尚未验证；没有联机测试条件时记录为未测。

## 启动与预览

在 Forge 1.20.1 实例中替换旧 JAR，确保实例里只放一份本模组。找一处白天、能看见地面和墙面的区域。预览命令仅在本机播放画面，不发起服务端攻击，也不改变生命值、命途经验或冷却。

先测试毁灭、智识、虚无、同谐、记忆和欢愉：

```text
/starrailvfx mode enhanced
/starrailvfx preview destruction_rage
/starrailvfx preview destruction_burn
/starrailvfx preview destruction_desperate
/starrailvfx preview erudition_echo
/starrailvfx preview erudition_final
/starrailvfx preview nihility_mark
/starrailvfx preview nihility_spread
/starrailvfx preview nihility_end
/starrailvfx preview harmony_resonance
/starrailvfx preview harmony_afterglow
/starrailvfx preview harmony_concert
/starrailvfx preview harmony_unison
/starrailvfx preview remembrance_record
/starrailvfx preview remembrance_echo
/starrailvfx preview remembrance_eternal
/starrailvfx preview elation_burst
/starrailvfx preview elation_grand
/starrailvfx preview toughness_hit
/starrailvfx preview toughness_break
```

然后回归首批三途：

```text
/starrailvfx preview hunt_strike
/starrailvfx preview hunt_reverse
/starrailvfx preview preservation_wall
/starrailvfx preview preservation_counter
/starrailvfx preview abundance_heal
/starrailvfx preview abundance_manna
/starrailvfx preview abundance_mercy
```

巡猎的普通四箭与强化八箭都使用巡猎增强材质，分别检查：`hunt_strike` 是普通四箭，`hunt_reverse` 是强化八箭。重点看外围箭和中央终结箭是否都有青蓝边缘泛光，中央命中后的背景折射环是否锚定在落点；两种动作的箭数和节奏应保持原样。

韧性受击与击破预览是轻量基础网格，不使用后处理；检查两者都能显示且 `status` 中后处理全屏绘制数为 0。

### 六途视觉重点

- **毁灭：**裂火/火冠有红橙热辉和边缘泛光；普通蓄势攻击有较轻热浪，濒危强爆发折射范围和镜头反馈更明显。怒意层数保持轻量。
- **智识：**紫色演算线发光，目标周围出现扫描环；终局脉冲更强。真实战斗中只在实际受到追加伤害的目标显示效果。
- **虚无：**标记先向内收束并保留暗紫侵蚀边缘；扩散网格沿真实来源方向抵达新目标；终结先塌缩再释放紫色回响。
- **同谐：**玫粉光带与柔金音符发光；共鸣能看出三拍起伏，七阶强化更饱满。击杀回响应从死亡位置沿光带返回玩家；预览中用玩家前方的点模拟死亡位置。
- **记忆：**冰蓝雪晶有折射泛光；回响有短暂局部像素化和折返波，永恒回响的两拍更强。只改变画面，不冻结游戏或实体。
- **欢愉：**粉金棱面有彩色高光和轻微色散；大欢愉清楚表现两次错拍爆发，碎光仍保持粉色主调。

普通与强化应有强度差别，但不应整屏盖色或遮住实体。以 `/starrailvfx mode basic` 对照时应回到直接网格颜色，不残留屏幕效果。

## 全途与回退检查

```text
/starrailvfx mode basic
/starrailvfx preview nihility_mark
/starrailvfx mode enhanced
/starrailvfx preview nihility_mark
/starrailvfx status
```

确认增强模式运行时状态显示后处理可用，活跃命途动作期间全屏绘制数为 3，空闲或韧性预览时为 0。还要检查：

- 在“设置 → 视频设置 → 粒子”分别选“最少”“减少”“全部”，运行同一命途预览并用 `/starrailvfx status` 查看分配缓冲、绘制数与网格构建耗时。“最少”档的缓冲和采样最省；“减少”使用中档采样，在高分辨率下缓冲可能因 1080p 上限而与“全部”相同；攻击形状、伤害和触发不受画质档位影响。用 F3 显示 FPS，同一地点、同一预览比较档位，不需要用性能更改来追求某个固定 FPS。

- 第一/第三人称、转动视角、移动目标和有墙遮挡的目标；效果应锚定世界实体或事件坐标，不跟随准星，不穿墙出现。
- 最少/减少/全部粒子设置、窗口缩放、F3+T 资源重载、暂停恢复、退出再进世界。
- 观察是否出现黑屏、残留像素块、过强色散、闪烁或日志中的着色器错误。若后处理不可用，基础网格仍应正常显示。
- `/starrailvfx strength 1.5` 可临时增强调试，之后用 `/starrailvfx strength 1` 恢复默认值。镜头震动只用于巡猎与毁灭强爆发，可单独用 `/starrailvfx shake false` 关闭。

若六途外观没有明显区别，或某个预览命令报错，告诉我命令名和画面表现即可；实际技能触发、目标同步和整合包兼容仍需在对应实战/模组组合中确认。
