# 1.9.0 发布前补测步骤

日期：2026-10-10。测试客户端已离线启动；本文件只列预期结果，不代表测试通过。HUD观感与遗迹挑战体验已确认，本次不重复完整验收。使用开启作弊的独立测试存档，测试命令会改变等级、践行度和基础属性。

## 一、九命途等级属性

卸下装备、光锥，先在行迹界面重置待测命途行迹，避免叠加影响核对。命途界面的“本等级累计属性加成”应与下表一致；角色详情显示的是包含基础值后的最终属性，不应直接拿最终暴击率与下表加成比较。

```mcfunction
/starrail path debug set hunt
/starrail path debug set_rank 7
```

依次将hunt替换为下表ID。每途查看命途界面和指南；再用set_rank 1至6查看各级，名称和值应该各占对应的一行，无合并、空名称或重复百分点提示。各级具体数值见《九命途等级属性与能力汇总》第5.1节。

| 命途ID | 七级累计加成 |
| --- | --- |
| elation | 暴击率10%、攻击力35%、暴击伤害35% |
| remembrance | 攻击力40%、暴击伤害40% |
| nihility | 效果命中30%、攻击力60%、击破特攻20% |
| preservation | 护甲55%、护甲韧性25% |
| destruction | 暴击伤害40%、攻击力40% |
| harmony | 护甲25%、生命25%、护甲韧性20% |
| abundance | 生命60%、治疗效果20% |
| erudition | 攻击力35%、暴击伤害35%、暴击率10% |
| hunt | 暴击率15%、暴击伤害40%、攻击力35% |

## 二、践行度与晋阶

设置等级会清空当前命途的阶段践行度。先测试巡猎：

```mcfunction
/starrail path debug set hunt
/starrail path debug set_rank 1
/gamemode survival
```

- 用自己的攻击击杀敌对生物，单次最多+1。扫击一次击杀多个敌人也最多+1；不要用/kill代替玩家攻击验证击杀奖励。
- 一级目标40；用set_rank 2、3、4、5、6分别查看目标80、120、160、200、240。一级实际积累40验证正常升级；后续阶段以界面门槛和下述试炼检查为主。
- 六级积累240后开启七级试炼；set_rank 7后显示300的极境门槛。七级积累300后修行次数+1，空手攻击力比修行前增加基础攻击力的10%，不会将已有命途倍率再乘1.1。最多10次。
- 300点和十次上限若没有实际跑完，请明确报告仅查看规则、未验证完整循环。

快速查看晋阶试炼目标可使用：

```mcfunction
/starrail path debug set_rank 6
/starrail path debug start_rank_trial
```

巡猎七级试炼应为击杀25、最高连续狩猎6，限时900秒，相邻击杀间隔不超过8秒。该命令绕过践行度，仅用于试炼测试，不能证明240门槛自然开启成功。

重点补测容易刷分的分支（先切对应命途、set_rank 2，确保不处于晋阶试炼）：

- 存护：真实格挡累计3次或实际承受敌对伤害累计6点后+1，奖励间隔12秒。只举盾而没挡到攻击、摔落和零伤害不能刷分。
- 丰饶：被敌对生物扣血后，实际累计恢复6点才+1，奖励间隔12秒；满血治疗、吸收生命损失、仅摔落后治疗不能刷分。用治疗药水或自然回血均可。
- 同谐：安全区域进食不加分；战斗中有效进食需每次至少间隔10秒，累计3次的辅助奖励间隔30秒。
- 其余命途按指南完成对应行为，检查一次最多+1；欢愉、记忆、智识的奖励间隔8秒，虚无新侵蚀分支10秒。

## 三、两个重点技能

### 巡猎逆时追猎

切hunt、set_rank 7，重置巡猎行迹以测试基础8秒冷却。快速连续击杀3个敌对生物，随后攻击另一只敌人：

- 满层下一击触发逆时追猎，技能增伤50%，冷却8秒。
- 冷却内重新满层并攻击：不能触发逆时追猎，也不能降级弹出“追猎一击”；普通攻击仍能造成伤害。
- 冷却结束后，在猎意未过期的情况下再次攻击可触发。猎意默认只有8秒，过期后需要重新叠层。
- 解锁相关七级行迹后再测，冷却应缩为5秒。

### 毁灭绝境

切destruction、set_rank 7，重置毁灭行迹，生存模式让敌人把生命打至最大值25%以下。

- 自动触发绝境，抗性I持续8秒；这8秒内连续多次攻击都有持续50%增伤，不是只强化一次。
- 立即喝治疗药水回到半血以上，持续增伤仍保留至8秒结束；低血血战、怒意和暴击会影响伤害对比，不能仅用两次随机伤害推算50%。
- 超过8秒后增伤结束；触发起12秒冷却内不能再次触发。重新低血并在12秒后观察是否能再次触发。
- 技能触发后立即切换命途再切回，不应绕过技能冷却。保存退出重进同样不能重置剩余冷却；单人暂停时间不算游戏时间。

## 四、属性上限与真实防御

在独立测试存档执行，先清命途并卸下装备、光锥：

```mcfunction
/starrail path debug clear
/attribute @s minecraft:generic.max_health base set 2000
/effect give @s minecraft:instant_health 1 10 true
/attribute @s minecraft:generic.max_health get
/attribute @s minecraft:generic.armor base set 100
/attribute @s minecraft:generic.armor_toughness base set 50
/attribute @s minecraft:generic.attack_damage base set 3000
/attribute @s minecraft:generic.attack_knockback base set 10
```

分别用/attribute @s <属性ID> get读取最终值，并查看角色详情/HUD。结果应超过旧上限1024、30、20、2048、5。护甲2、韧性1是默认基值，不是在指令设定基值后另外相加；装备、命途等修正会影响最终值。HUD可能用K/M缩写，属于正常显示。

自定义属性用下列命令确认“有效值”上限（get，不是base get）：

```mcfunction
/attribute @s starrail_sim:crit_rate base set 2
/attribute @s starrail_sim:crit_rate get
/attribute @s starrail_sim:effect_hit_rate base set 2
/attribute @s starrail_sim:effect_hit_rate get
/attribute @s starrail_sim:effect_resistance base set 2
/attribute @s starrail_sim:effect_resistance get
```

三者有效值都应为1，即100%。暴击伤害、击破特攻、治疗效果分别将下面ID的base set设为20000，再get，有效值都应为10000，即1,000,000%：

- starrail_sim:crit_damage
- starrail_sim:break_effect
- starrail_sim:healing_effect

最后检查超限护甲真实减伤，先恢复测试用暴击等属性或另建测试存档，清除状态效果；生命保持2000并治疗到满，生存模式：

```mcfunction
/effect clear @s
/summon minecraft:zombie ~3 ~ ~ {NoAI:1b,Invulnerable:1b,PersistenceRequired:1b}
/damage @s 20 minecraft:mob_attack by @e[type=minecraft:zombie,sort=nearest,limit=1]
```

比较伤害前后实际生命。护甲100、韧性50应仍扣血，低于无护甲同种20点伤害，但不会完全无敌。将护甲、韧性基础值提高到1000后，治疗、等待至少1秒，再施加相同伤害：扣血应进一步降低，默认减伤上限95%，不会变成零或负数。不要用摔落伤害验证护甲减伤。

核对保存退出重进、死亡重生后属性与HUD没有丢失/重复叠加；极端属性只用于确认上限，不拿它测试正常命途技能和践行度。
