# 1.23.0 多人联机测试清单

适用版本：Minecraft 1.20.1 Forge。此清单用于专用服务器和至少两名玩家的测试；目标是检查玩家状态是否隔离、方块与红石变化是否同步，以及最新修复在服务器上是否正常。**清单已编写，测试结果待填写；不能把构建成功当作多人验收通过。**

## 测试前准备

1. 优先使用专用服务器和两台客户端；如果只能通过局域网联机，也可先完成基础同步检查。
2. 服务端与每个客户端使用相同的 Minecraft 1.20.1 Forge 版本、所需前置模组和本轮测试包。将 `starrail_sim-1.23.0-test.jar` 放进每一端的 `mods` 文件夹，并移走同一模组的旧版 JAR，避免版本重复。
3. 本轮测试包 SHA-256：`4225357C0E16C90CB74924DC6CEFADFB888A90375BDE1804DAA0CAA8F436B912`。连接后确认两名玩家都能进入服务器，没有版本不匹配、注册表或资源加载报错。
4. 新建一个临时测试世界，确保静潮泽地和芦苇附近的区块是本轮新生成的。测试结束后保留存档，方便复现问题。
5. 为方便定位，给测试玩家临时 OP 权限（命令权限等级 2）。没有 OP 时，可按正常游戏路线进入命途遗境。两名玩家分别称为 A、B；涉及探索记录时，先确认双方都没有对应群系的记录。

## 测试步骤

### 1. 两名玩家进入同一维度

- A、B 先后执行 `/starrail dimension enter`，进入命途遗境。
- A 放置一个容易辨认的方块，B 确认能看到；再由 B 破坏，A 确认方块同步消失。
- **通过标准：**两人进入同一世界位置体系，方块放置和破坏在两端一致，没有掉线、卡死或区块不同步。

### 2. 新群系发现记录按玩家分别保存

- A 执行 `/starrail dimension locate region star_scree_highlands`，按命令返回的坐标前往星砾高地；B 留在其他群系，不跟随。
- A 查看行旅档案/指南中的群系发现记录；B 查看自己的记录。
- 然后让 B 独自前往静潮泽地（命令为 `/starrail dimension locate region stilltide_marsh`），再分别查看双方记录。
- **通过标准：**进入群系的玩家收到发现提示并增加自己的记录；另一名未进入该群系的玩家不应被代为记录。玩家退出并重新连接后，个人记录仍保留。

### 3. 泽地生成与芦苇同步、掉落

- 在新生成的静潮泽地区块检查泽地腐殖土、浅水洼、芦苇和附近湿生植物。A、B 到同一片区域互相确认生成位置一致。
- A 在合适基底上放置一株两格芦苇，B 确认上下两格都出现；随后由 A 正常破坏整株，双方观察掉落与拾取结果。
- 再由 B 破坏另一株自然生成芦苇，避免只测到单一玩家操作。
- **通过标准：**自然生成的芦苇为两格高；放置和破坏状态两端同步；每株只产生一个芦苇物品，不重复、不丢失。

### 4. 谐振晶与红石混铺传播

- A 铺设一条短测试线：拉杆/红石块 → 原版红石粉 → 谐振晶线 → 原版红石粉 → 红石灯。B 站在旁边观察。
- 开关电源，观察灯是否点亮、沿线信号是否传播；关闭后确认灯熄灭。再由 B 改为谐振晶起始、原版红石粉连接的布局，重复一次。
- **通过标准：**原版红石粉和谐振晶能相互连接并传播信号；两名玩家看到的线形状态和灯状态一致，拆除/重放后更新正常。谐振晶通电时应显示青蓝粒子，而不是红色粒子。

### 5. 光影与透明贴图检查

这是客户端视觉检查，建议先在关闭光影时观察，再启用 `ComplementaryReimagined_r5.9.3` 重复。若两名玩家都参与，可让一端开光影、另一端关闭，确认方块状态同步且两端各自的贴图都正常。

- 检查双格芦苇的透明区域仍能看穿，不出现整片不透明色块；上下两格都检查。
- 检查谐振晶线的透明区域和线形贴图；通电后确认粒子为青蓝色。
- 检查星砾垫草是否贴合支撑方块，没有缝隙或透明边缘异常。
- 在创造模式中检查九类命途遗迹锚点，留意纹理边缘是否保留半透明效果、是否出现整面不透明或消失。
- 放置星穹列车，确认开关光影后都能看到模型；可再检查手持列车物品的缩略图。
- **通过标准：**开关光影时这些资源的轮廓、透明区域和可见性保持合理；谐振晶粒子持续呈青蓝色。

### 6. 曜金、霞铜配方和物品显示

- A 先悬停原料确认名称为“曜金锭”，按标准配方分别制作曜金剑、镐、斧、锹、锄五种工具；B 用霞铜锭制作一种霞铜工具。逐个确认工作台输出非空且产物是对应的模组物品。
- 用普通原版金锭再制作一个原版金工具，确认原版配方仍正常。双方不要共用工作台输入物品，以便区分各自背包结果。
- A 手持曜金工具，B 从正面和侧面观察；然后交换角色。对两套工具至少各检查一次侧视厚度，并由另一客户端观察第三人称模型。穿戴曜金/霞铜护甲后检查头盔正面是否露出面部、手臂背面有无错贴图，再转身检查侧面。
- **通过标准：**五种曜金自定义配方输出正确物品；普通金工具配方仍有效；手持工具和武器侧面不再像薄片/镂空，盔甲头盔与手臂 UV 正常；物品不会出现在另一名玩家背包中。

### 7. 床与维度返回

- A 在命途遗境放置并使用床，确认没有爆炸或伤害；B 观察床和周围方块没有异常变化。
- A 使用 `/starrail dimension return` 返回，B 也单独测试一次。
- **通过标准：**床可使用且不爆炸；两名玩家都能正常返回各自进入命途遗境前的位置。

### 8. 断线重连与服务器重启

- 两人分别记录群系发现状态。A 在测试区域留下标记方块并放置一段红石/谐振晶线路。
- 先让 A 退出再重新加入，检查其个人记录和世界状态；再正常关闭并重启服务器，两名玩家重新加入复查。
- **通过标准：**个人探索记录没有串到另一玩家；已保存的方块、芦苇和线路状态仍正确。若本轮时间有限，可将服务器重启项单独标为“未测”，不要记为通过。
