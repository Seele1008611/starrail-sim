# 1.10.0 遗器属性成长与强化数值表

日期：2026-10-11。状态：**成长与经济数值已由用户确认；尚未接入游戏。**

本表细化[1.10.0版本计划](../版本规划/1.10.0版本计划.md)中的二至五星主副属性、强化经验、分解与合成经济。五套套装效果及本表成长、经验和经济数值均已由用户确认。本文角色面板测算暂不叠加套装加成，以便单独呈现遗器词条成长。数值尚未接入游戏；HTML和原生UI中的属性、强化数据仍是演示值。

## 一、已经确定的边界与数值

沿用六槽：外圈头部、手部、躯干、脚部；内圈位面球、连结绳。二至五星分别最高+6/+9/+12/+15；每3级补副属性或强化副属性，最多4条；二星升满只有2条。

本次确定主属性成长值、副属性单次数值、随机权重和逐级经验表。材料单价、分解基础收益、80%经验返还、普通合成/尘脂/骰子成本沿用此前版本计划中的方案；干涉密钥制作成本已确认。

设计目标：

- 六槽升满能带来明显提升，二至四星可用于过渡，不必等五星才装备。
- 数值生命与攻击采用Minecraft尺度，保留七级命途、行迹、光锥和极境的成长意义。
- 装备带来的固定值与百分比均可查看来源；不修改玩家属性基值。
- 主属性固定成长；副属性存在随机性；所有随机结果由服务器生成并保存。
- 暴击率、效果命中、效果抵抗最多100%，溢出不转化；暴击伤害、击破特攻、治疗效果最多1,000,000%。

## 二、主属性

### 2.1 部位候选池

| 部位 | 主属性 |
| --- | --- |
| 头部 | 数值生命，固定 |
| 手部 | 数值攻击，固定 |
| 躯干 | 生命%、攻击%、护甲%、暴击率%、暴击伤害%、效果命中%、治疗效果% |
| 脚部 | 生命%、攻击%、护甲% |
| 位面球 | 生命%、攻击%、护甲% |
| 连结绳 | 生命%、攻击%、护甲%、击破特攻% |

不加入移动速度、攻击速度、元素伤害、能量恢复。护甲韧性只进入副属性池，本版不增加韧性主属性。

**随机主属性：同部位候选等权。** 躯干每种1/7，脚部与球每种1/3，绳每种1/4；头部、手部100%为固定属性。选套装不改变主属性概率。普通合成可选择套装和部位，主属性按相同权重生成；尘脂定向合成直接使用玩家选择的合法主属性。

### 2.2 成长公式

`主属性值 = 品质系数 × (A + B × 当前强化等级)`

| 品质 | 品质系数 | 最高等级 |
| --- | ---: | ---: |
| 二星 | 0.4 | +6 |
| 三星 | 0.6 | +9 |
| 四星 | 0.8 | +12 |
| 五星 | 1.0 | +15 |

| 主属性 | 五星 +0 基数 A | 每级增量 B |
| --- | ---: | ---: |
| 数值生命 | 3 | 0.8 |
| 数值攻击 | 0.75 | 17/60（约0.283333） |
| 生命% / 攻击% | 8 | 2 |
| 护甲% | 10 | 2.5 |
| 暴击率% | 5 | 1 |
| 暴击伤害% | 10 | 2 |
| 效果命中% | 8 | 2 |
| 治疗效果% | 6 | 1.6 |
| 击破特攻% | 12 | 3.2 |

百分比行的数字单位为%；例如攻击38代表攻击力+38%，服务器比例值为0.38。数值生命以生命点计，2点为原版1颗心；数值攻击以原版攻击伤害属性计。

固定值和比例都不先取整到整数。公式系数按表中原始精度计算；数值攻击的每级增量按17/60精确计算，以保留+0基数0.75并使五星+15正好达到5。百分比转成属性比例时再除以100。成长按基础公式重算，不在上一级显示值或已格式化的显示值上反复叠加。

以下是一条副属性**首次生成或一次强化**的数值。低、中、高三档分别为中档×0.8、×1、×1.2，每档概率1/3。首次生成、补新词条、提升已有词条均使用相同档位规则。

不因遗器等级提高单次副属性档位；已有副属性的初始值不随主属性成长自动增长。

### 3.2 初始化与选择权重

| 品质 | 初始副属性条数 | 概率 | 满级结果 |
| --- | --- | --- | --- |
| 二星 | 0 | 100% | +3/+6各新增1条，共2条，无强化已有条 |
| 三星 | 1 / 2 | 80% / 20% | 初始1条：最终4条无强化；初始2条：最终4条、强化1次 |
| 四星 | 2 / 3 | 80% / 20% | 初始2条：最终4条、强化2次；初始3条：最终4条、强化3次 |
| 五星 | 3 / 4 | 80% / 20% | 初始3条：最终4条、强化4次；初始4条：最终4条、强化5次 |

14个副属性ID等权，排除主属性ID与已有副属性ID后，每次从剩余合法ID中等概率抽取；依次抽取，不先抽重复再丢弃。主属性为攻击%时仍允许数值攻击，数值护甲与护甲%也同理。

已有4条时，每条被强化的概率为25%，再独立抽取档位。没有保底指定词条，也不根据当前命途偷偷偏向某类属性。初始化条数、属性ID、档位和强化目标使用独立随机选择。

### 3.3 数值累计与记录

每条保存：属性ID、初始档位和值、首次出现等级、后续强化事件。最终值为初始值加该条历次强化增量。

例：五星初始暴击率中档1.5%，+6和+12分别抽到高档1.8%、低档1.2%，最终为4.5%，该条强化次数为2。补第四条属于新增事件，不计为某条已有副属性的强化。

批量强化跨越多个3级节点时按+3、+6、+9、+12、+15顺序逐个处理。任何等级最多结算一次；保存节点处理进度，重进、换装、重新同步均不重抽。

### 3.4 变量骰子

沿用只作用于未装备、未锁定、无待确认结果的五星+15遗器；消耗1个变量骰子。

- 四条副属性ID、初始基础值、主属性、等级和投入经验保持不变。
- 初始3条的遗器保留4次强化事件；初始4条的遗器保留5次强化事件。
- 每次事件重新等概率选择四条之一，并抽取低/中/高档，从原始基础值重新求和。
- 补第四条的基础值同样保留，不重抽成第五次强化。
- 旧结果与新结果并排显示，玩家二选一；保留旧结果仍消耗骰子。
- 候选生成、扣除骰子和保存待确认状态必须一次结算；重登恢复同一候选。
- 重掷不提高分解收益，不改变投入经验，不把上次候选增量继续叠加。

### 4.2 消耗与取整

本版所有升级费用都是100的整数倍，仅使用晶块强化，正常流程不会产生不足100的进度。投入经验保存为整数，仍保留等级间进度字段，供恢复及后续材料扩展使用。

- 玩家可选目标等级或投入数量；预览实际消耗、达到等级、将跨过的节点。
- 自动将实际消耗限制在升满所需晶块数，未使用晶块留在库存。
- 例如五星+14升+15只扣12晶块，选择投入20时另外8个不扣。
- 材料不足、满级、锁定的待消耗物品、待确认骰子结果等无效操作不扣材料。
- 已装备或已锁定的遗器允许正常强化；锁定用于防止分解/作为材料，不能误判为禁止培养。
- 本版不直接吞其他遗器强化，先分解成晶块。投入经验不包含遗器自身的基础分解价值。
- 每次服务器成功接纳的经验只记录一次；撤销失败请求不累计经验。

若后续加入其他单位的经验材料，需要另定满级不足一个材料单位的处理规则；不能在本版实现中直接吞掉余量。

使用干涉密钥定向副属性时，五星+0直接生成所选的四条初始副属性；后续+3、+6、+9、+12、+15五次成长均随机强化其中一条。初始档位和强化数值沿用既有随机规则。

### 5.2 已强化物品返还

`晶块收益 = 品质基础晶块 + floor(实际投入经验 × 0.8 / 100)`

| 品质 | 满级投入经验 | 基础晶块 | 经验返还晶块 | 满级总收益 |
| --- | ---: | ---: | ---: | ---: |
| 二星+6 | 900 | 1 | 7 | 8 |
| 三星+9 | 1,800 | 1 | 14 | 15 |
| 四星+12 | 4,200 | 3 | 33 | 36 |
| 五星+15 | 7,700 | 5 | 61 | 66 |

取整对每件物品分别处理，再加总批量收益。例如两件各投入300经验的二星，每件返还1+2=3晶块，合计6，不把600经验合并取整后多返1晶块。

五星+15选择残骸仍只获得10残骸；界面同时列出晶块模式66晶块与残骸模式10残骸，并说明后者放弃经验返还。两种奖励不能同时领取。

### 5.3 经济节奏与循环

按此前每次决斗场结算1件、五级以上必出五星的方案，只计算材料数量，不估计尚未确定的每场时间：

| 目标 | 材料投入 | 等价+0五星分解数量 |
| --- | --- | ---: |
| 五星+12 | 46晶块 | 10件为50晶块，余4 |
| 五星+15 | 77晶块 | 16件为80晶块，余3 |
| 六件五星全部+15 | 462晶块 | 93件为465晶块，余3 |
| 普通指定套装/部位合成 | 100残骸 | 10件 |
| 自制尘脂再定向合成 | 300残骸 | 30件 |
| 自制干涉密钥并定向四种副属性合成 | 600残骸 | 60件 |
| 自制尘脂和干涉密钥并同时定向主副属性 | 800残骸 | 80件 |
| 自制骰子并重掷一次 | 300残骸 | 30件 |

此表不包含保留下来的装备、同场其他来源或后续套装效果，因此实际需要的挑战次数还取决于玩家保留与分解选择。每件五星只能选一种分解用途；不能同时用于晶块、残骸和装备。

循环对照：

- 10件+0五星分解得100残骸，合成1件五星后再分解只有10残骸或5晶块。
- 一件五星升满消耗77晶块，随后分解返66，其中5是这件物品原有基础收益；相对于直接分解它得到5晶块，培养后实际少收16晶块。
- 强化经验返还始终按80%向下取整；合成不继承被消耗遗器的经验，骰子不增加返还资源。
- 普通合成→分解最多将100残骸转换为5晶块，不能逆向免费转换晶块为残骸。

## 六、属性叠加与现有系统衔接

### 6.1 遗器修正提案

同属性先汇总六件遗器主副属性：

- 数值生命、攻击、护甲、韧性：各自汇总为一项ADDITION修正。
- 生命%、攻击%、护甲%、韧性%：各自汇总为一项MULTIPLY_TOTAL修正，因子为1+六件比例之和。
- 暴击率、暴击伤害、效果命中、效果抵抗、击破特攻、治疗效果：各自汇总为一项ADDITION修正，比例值直接相加，再按既有属性上限裁剪。

例如三件攻击主属性各38%，遗器攻击乘数是1+114%=2.14，不是1.38的三次方。副属性攻击%继续加到114%内；不能每槽各装一项MULTIPLY_TOTAL产生额外复利。

现有命途/极境、行迹、光锥修正维持各自规则。七级命途攻击与极境已经合并为一项：记忆满极境为1+40%+100%=2.4；不能再把40%和100%分别相乘。

原版属性实例按照ADDITION、MULTIPLY_BASE、MULTIPLY_TOTAL顺序结算；已有生命/攻击行迹使用MULTIPLY_BASE，护甲/韧性行迹使用MULTIPLY_TOTAL。遗器不会在UI额外乘第二次。

护甲的实际减伤依旧受现有防御公式、伤害来源和护甲穿透等影响，不能将护甲+47.5%描述成受到伤害减少47.5%。击破特攻与治疗效果沿用当前已实现机制。

### 6.2 近战与远程接入要求

现有远程助手排除主手武器修正，依靠投射物自身伤害提供武器部分；它与近战的手持武器数值来源不同。遗器固定攻击加入后，必须统一其余属性修正的运算顺序，不能在箭矢伤害上直接再加一次剑的攻击力。

当前远程助手的MULTIPLY_BASE计算使用玩家基值，而属性实例会在加法修正之后处理比例。加入遗器固定攻击后，这处差异应在接入时修正，并保持既有投射物伤害基础、附魔及暴击/命途触发顺序。这里是代码接入约束，不表示本次已修改或验证远程伤害。

### 6.3 UI与保存

来源详情区分遗器主属性、副属性、套装效果；总览只显示实际生效的总值。暴击率等达到100%可标记已达上限，超出部分仍可在来源列表查看，不转成其他属性。

数值显示最多两位小数，移除末尾0；微小正加成可显示“<0.01”，不得显示成没有加成。计算与存储保持原始精度，不用显示值参与重算。

指令设置攻击基值3000或护甲/韧性基值100后，换装与重登都必须保留；只移除本系统修正，不重新设回1、2、1。装备变化裁剪超过上限的当前生命，不自动补满，不视作治疗或践行行为。

## 七、与现有成长组合的数值对照

以下是依据当前代码修正类型及本表已确认数值的算术示例，**没有运行游戏验证**。不包含套装、随机伤害波动、抗性、防御、附魔、命途触发技、光锥触发效果；表中的攻击力不是最终每次攻击伤害。

### 7.1 入门与裸装

| 场景 | 属性结果 |
| --- | --- |
| 无命途、无盔甲：二星+6头/手，其余槽不提供相关主副属性 | 生命23.12、空手攻击1.98 |
| 无命途、无盔甲：五星+15头/手，其余槽不提供相关主副属性 | 生命35、空手攻击6 |
| 上述五星手部，持下界合金剑，不带其他攻击加成 | 攻击1+7+5=13 |
| 五星满级头部，四个可变主属性均为生命38%，无生命副属性 | 生命(20+15)×2.52=88.2 |

### 7.2 记忆与巡猎攻击

选择五星满级头、手；躯干暴击率20%；脚、球、绳各攻击38%。为展示主属性影响，副属性不提供攻击修正。

| 场景 | 持下界合金剑的攻击力 |
| --- | ---: |
| 记忆七级，尚未开启行迹/极境 | (8+5)×1.4×2.14 = 38.948 |
| 记忆七级、满攻击行迹60%、满极境100% | (8+5)×1.6×2.4×2.14 = 106.8288 |
| 巡猎七级、满攻击行迹50%、满极境100%，无光锥 | (8+5)×1.5×2.35×2.14 = 98.0655 |
| 上述巡猎，装备叠影I“如泥酣眠”的常驻攻击10%与命途专属常驻攻击10% | 上述结果×1.1×1.1 = 118.659255 |

同一记忆满成长角色不装备遗器时攻击为8×1.6×2.4=30.72；该示例装备后约为原来的3.48倍。五套套装效果现已确认，进入组合平衡核对时还要将攻击、伤害、暴击伤害、护甲、生命、治疗和护盾套装效果分别叠加检查，不能只按遗器主副属性单独定值。

暴击率例：巡猎基础5%+七级15%+满行迹10%+躯干20%=50%；还可通过副属性增加，但最终最多100%。如泥酣眠的触发暴击率等临时效果未计入本例。

### 7.3 存护与盔甲

采用五星满级头/手，其余四个主属性均护甲47.5%，六件各提供一次中档数值护甲0.5、数值韧性0.2、韧性2%副属性。这些副属性合法，第四条及后续升级选择其他属性；不假设每件都强化防御。

| 场景 | 护甲值 | 护甲韧性 |
| --- | ---: | ---: |
| 裸玩家，只装备上述遗器，无命途行迹 | (2+3)×2.9=14.5 | (1+1.2)×1.12=2.464 |
| 下界合金全套，只装备上述遗器，无命途行迹 | (2+20+3)×2.9=72.5 | (1+12+1.2)×1.12=15.904 |
| 下界合金全套、存护七级、满防御行迹60% | 25×1.55×1.6×2.9=179.8 | 14.2×1.25×1.6×1.12=31.808 |

高护甲方案会显著影响当前防御机制，不能直接据此承诺决斗场难度合理。游戏内实现后，需要用户同时观察物理受伤、生存能力和其他伤害来源；如防御过强，再讨论护甲主属性和套装调整，保留属性上限扩展与指令基值功能。

### 7.4 丰饶生命

同7.1的四件生命主属性，无生命副属性、无光锥。丰饶七级生命+60%、满生命行迹+60%，满级头部+15：

`(20+15) × (1+60%行迹) × (1+60%命途) × (1+152%遗器) = 225.792生命`

此处为最大生命，不会自动治疗到此数值。躯干改为治疗效果30%时，生命主属性只剩三件114%，对应最大生命191.744；治疗效果则增加30%，需要同时比较实际治疗体验。
