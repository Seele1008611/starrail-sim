# 命途遗境方块贴图风格规范

## 目标

让方块在单独查看时有清晰材质身份，在大片地面、墙体或矿脉中连续铺设时保持安静、耐看，避免高频细节和强反差造成视觉疲劳。采用 Minecraft 的 16×16 像素质感；不因为原版常用白色石英，就把新材质统一改成白色。

## 画面规则

- 游戏内方块贴图固定为 16×16 像素，256 个像素位置都可用于表达材质；不能默认降到 8×8 再放大，否则会把实际细节减半。
- 保持 Minecraft 像素画的清晰色块和克制对比，但不设固定颜色数量上限。根据材质保留必要的明暗、轮廓和识别细节，避免为了减少颜色而把细节抹成大色块。
- 每种材质保留自己的主色和识别方式：土、砂、石、砾、矿石、金属和结构板不能套同一底纹或被统一染色。
- 自然地表采用低频大色块。矿脉和晶簇使用少数、较大的识别簇，不撒满均匀小亮点；岩石纹理避免重复的强对角线或网格。
- 建筑和设备方块用宽面板、少量接缝和有限的功能色。青色、金色等高亮只用于确实需要识别的灯芯、导光线或警示条。
- 砖纹必须可平铺：贴图边缘不得保留一圈外框或阴影，左右、上下相接处不能出现加倍的深色缝。墙、楼梯、台阶共用同一砖纹时要一起检查。
- 玻璃使用 RGBA 半透明贴图；边缘不放连续粗框、角标或强亮线，确保相邻方块连接时不显出重复框格。每次都要检查透明度和至少 4×4 连铺效果。
- 透明底母图若包含分散的面片或 UV 排布，不能把整张画布直接缩成方块贴图；先提取或补成一个完整的正面，再缩至 16×16，并确认有效图像没有因透明区域过多而消失。
- 非完整立方体或自定义元素模型必须显式设置 `textures.particle`，指向实际使用的方块贴图，避免破坏粒子显示缺失贴图。
- 不把图像生成器的棋盘格预览误当作透明背景；贴图底面应是完整材质，透明区域必须来自真实 Alpha 通道。

## 处理流程

1. 生成或编辑高分辨率母图，按中文名称归档到 `崩铁/物品/` 下与素材性质对应的分类：方块和地表材料放 `方块与材料/`；植物、作物、种子和食物放 `食物与种子/`；工具装备、命途内容放各自分类。不要把不同性质的原稿默认都放进 `方块与材料/`。
2. 替换现有素材前，分别备份物品文件夹母图和 `src/main/resources/assets/starrail_sim/textures/block/` 中的游戏贴图。
3. 先从母图中裁出、矫正并补全真正要用的材质表面，再把细节映射到 16×16 逻辑像素网格。可以在放大的工作画布上绘制：例如使用 256×256 画布，每个 16×16 工作像素格填一种颜色；关闭抗锯齿，完成后用最近邻缩至 16×16。高分辨率母图只作构图、取色和材质特征参考，不能直接缩小后不检查就作为最终贴图。禁止自然地表或结构方块默认经过 8×8 中间画布；缩放预览时才使用最近邻放大。透明底的分散面片素材先提取完整方形面，再按玻璃 Alpha 规则处理。
4. 检查 16×16 原尺寸和放大预览，确认没有整齐的 2×2 重复像素把有效分辨率降为 8×8；同时检查至少 4×4 连铺效果、玻璃 Alpha、尺寸以及资源名映射。确认后才替换游戏内资源。
5. 原图是留档母图；游戏资源必须是对应的 16×16 文件。归档类别按素材性质确定；游戏内显示为可放置方块的植物，其原稿按植物类别放入 `食物与种子/`，不因此混入方块材料原稿。
