# 当前工作流程与文档索引



整理日期：2026-11-08。本页是流程导航；长期协作要求以仓库根目录 [AGENTS.md](../../AGENTS.md) 和用户最新明确指令为准。专项文档只维护各自适用范围，历史版本记录不作为当前操作命令。

## 文档适用顺序

1. 用户当前明确要求及最近确认的修改。
2. AGENTS.md 中仍有效的长期规则。
3. 下列专项流程。实验参数、某批资产的授权和旧版本验收不得推广为所有任务的规则。
4. 开发记录、历史版本计划与原型说明用于追溯；其中“当前”“待测试”只指记录当时。当前状态看版本计划顶部摘要；实际行为须核对当前源码。

## 专项入口

| 范围 | 当前入口 | 关键边界 |
|---|---|---|
| 物品图标 | [生图与裁切](物品图标生图与裁切经验.md) | 分有原图参考与原创两条路线，成品含透明边距边长50–80像素；每9件一批透明3×3，逐件恢复网格 |
| 方块表面 | [方块规范](方块贴图规范与生图队列.md#方块贴图规范) | 独立队列，每9张满铺3×3；普通建筑/地表表面16×16 |
| 生图排队 | [待生成清单](方块贴图规范与生图队列.md#生图队列) | 两类分别累计；不足9不生图，不擅自填充目标 |
| 本地网格恢复 | [工具说明](../贴图工具/pixel-grid-recovery/SKILL.md) | 逐件恢复实际网格；50–80像素是物品成品边长，旧批次参数见物品流程 |
| 实体建模 | [Blockbench流程](../模型资产/Blockbench/建模流程与经验.md) | 桌面可用→简化三视图→方体比例稿→用户审阅→贴图完善 |
| 探索建筑 | [设计与调研经验](../遗迹设计/探索建筑设计与调研经验.md) | 先更新版本计划；环境、路线、威胁与奖励共同设计，标明来源与验证边界 |
| 声音制作 | [本地音效环境](../音效模型/README.md) | 本地模型优先，不同物种不复用；许可与原始音源须留档 |
| 视觉特效 | [类型与实现参考](系统设计/视觉特效类型与Forge实现参考.md) | 每个特效至少两种类型，记录组合与实机状态 |
| 构建交付 | [协作规则](../../AGENTS.md) | 测试包build/libs，正式包libs；完整任务结束且交付测试时再打包 |

所有贴图每个目标只生图一次。即使首稿质量不足，重新生图、换seed或局部生成式重绘前仍须询问用户并收到明确授权；裁切、网格恢复、透明度检查与PNG优化是原稿处理。实体和盔甲UV也受单次生图约束，但物品/方块的九格布局不直接用于实体UV。
