# 1.10.0 遗器界面原型

入口：[遗器界面设计图.html](遗器界面设计图.html)。直接用浏览器打开，无需安装依赖或启动服务。

## 当前内容

- 三套外圈：野穗伴行的快枪手、云无留迹的过客、净庭教宗的圣骑士。
- 两套内圈：太空封印站、不老者的仙舟。
- 使用“崩铁/遗器”中的16张原尺寸透明像素风格PNG，未复制一份贴图；原型路径与项目目录一起保留。
- 六槽总览、库存部位/套装/星级/锁定筛选、右侧详情、装备替换与卸下、锁定。
- 五套用户确认的两件/四件效果已写进套装摘要与遗器详情；预览页只展示设定，不执行战斗结算。
- 六槽布局不显示人物：外圈头部左上、手部右上、躯干左下、脚部右下，固定在四角；内圈位面球在中心区域左上、连结绳在右下，斜向排列。六个装备槽边框均为圆形，部位名称放在圆框下方。
- 二至五星强化上限与每3级副属性节点；晶块强化及结果预览。
- 五星晶块/残骸分解二选一，分解确认与已装备/锁定项保护。
- 普通五星合成、指定主属性合成、尘脂与骰子制作。
- 变量骰子仅用于+15五星；新旧结果对比、选择保留，保留旧结果仍消耗骰子。
- 本页待选重掷结果在切换功能页时保留，处理之前不能继续操作该物品。

## 设计边界

五套套装的两件/四件效果已由用户确认，并已同步至原型和原生遗器详情；此处仅展示设计效果，不代表游戏战斗中已实现。属性数值、副属性增量及强化经验仍为演示，最终按数值设计表替换。合成/分解材料基础成本沿用版本计划；演示强化每晶块推进1级，因此强化投入及返还示例不作为正式经验表。

四种材料使用“崩铁/物品”中的正式原尺寸透明像素风格PNG：遗失晶块、遗器残骸、自塑尘脂、变量骰子；自塑尘脂已替换原星琼占位图。

用户已明确：替换素材时保留生成的原尺寸像素风格图片，不用缩小版本覆盖。当前20张素材均为1254×1254，直接复制图像编辑结果，未经缩放或重编码。此前覆盖为64×64的16张遗器已全部纠正；将来游戏接入需要的小尺寸贴图应单独导出到游戏资源目录。预览拼图仅用于浏览，不替代原素材。

仅为本地HTML演示，无游戏数据连接、服务器事务或重登存档实现；刷新页面恢复初始数据。适配桌面及窄窗口，不擅自运行客户端、测试或下载依赖。

## 查看交互

1. 在装备总览点击六槽或库存，查看右侧详情；点击“装备”可替换对应部位。
2. 切换强化页，为二星遗器强化到+6可看到最终两条副属性；五星可强化到+15。
3. 分解前先卸下并解锁；五星可分别查看晶块/残骸收益。
4. 合成页选择内/外圈套装和部位，躯干、脚部、球、绳支持定向主属性；头部、手部无需尘脂。
5. 重掷页点击“选择可重掷遗器”，示例库存有+15「圣骑的沉默誓环」，可直接体验新旧结果选择。
6. “重置演示”恢复全部示例库存与材料。

## 本轮界面细化（2026-10-10）

- 保留外圈四角、内圈左上/右下的圆形六槽；选中与悬停增加轻微描边光效。
- 装备贡献默认折叠，可查看六件主副属性合计；不与玩家最终属性混淆。
- 库存增加名称搜索、主属性与装备状态筛选、四种排序、清空筛选和空结果提示。卡片显示主属性、装备/锁定/待选状态。
- 未装备遗器的详情可与当前同部位比较，逐项显示增减；换装确认使用同一比较表，避免不同主属性被直接当作一个数字比较。
- 强化支持提升1级、提升3级、升至上限；展示3级成长节点、材料持有量与消耗，完成后显示前后变化。
- 合成展示目标部件、品质与主属性模式；材料不足、满级、锁定、已装备、重掷待选等状态提供明确原因。
- 右侧详情独立滚动，比较表与确认弹窗适配窄窗口；折叠汇总避免主页面长期堆满数值。

以上仍为界面交互演示，沿用原有示例成长值；新增数值提案尚未当成确认数据接入。未运行浏览器自动测试或游戏客户端。

## 动效细化（2026-10-10）

- 切换功能页：内容淡入并轻微上移，标题短距离滑入，约300～350毫秒。
- 选择遗器：库存卡片短暂描边发光，右侧详情淡入，图标由小到正常尺寸；同一选择的普通刷新不重复整页过渡。
- 六槽：选中槽外环缓慢呼吸，内圈轨道缓慢旋转；换装时目标槽光环扩散、图标落位。
- 库存：筛选结果变化时卡片依次出现，最多延迟约200毫秒；悬停图标上移3像素，点击有短暂光圈。
- 强化：目标与已结算节点短暂发光，完成面板出现金色扩散环及少量方形光屑，前后变化仍可正常阅读。
- 合成：获得新遗器时目标预览和新卡片发光；分解时旧遗器淡出，获得材料的计数区域亮起。
- 重掷：候选生成时目标亮起青色光屑，新旧结果行依次显示；锁定状态变化也有短促反馈。
- 材料数量变化采用约360毫秒的数字过渡，确认弹窗采用约260毫秒的出现过渡。

动画只负责视觉反馈，不延迟操作结算，不阻止连续操作，不参与随机结果生成。局部光效约1秒内自动清除；原图不修改，无新增依赖或下载。系统开启“减少动态效果”时关闭循环、过渡和光屑。未运行自动测试或游戏客户端。

后续游戏内使用相同触发点与时间节奏实现UI动画；HTML中的DOM/CSS动画本身不会直接带入Minecraft。

### 全控件与内外圈待机动效

- 所有启用的按钮、下拉筛选、搜索框、复选框和折叠栏提供悬停、按压或聚焦反馈；选项改变有短暂青色强调。键盘Enter/空格操作也有反馈，不改变原生键盘行为。
- 弹窗中的确认、取消和关闭按钮直接显示光效；关闭时保留约160毫秒的纯视觉淡出副本，实际操作立即完成，副本不可点击且不含重复ID。
- 外圈增加金色刻度与双段流光轨道，流光24秒顺转一周；内圈青色流光16秒反转一周，虚线轨道独立缓慢转动。
- 外圈图标5.6秒轻微浮动，内圈4.8秒；所有槽的呼吸边框采用错开的相位，槽位及文字位置保持固定，空槽不浮动。
- 鼠标悬停或键盘聚焦时，目标槽内图标暂停浮动并略微提亮；移开后继续待机。
- 页面重绘沿用当前时间相位，换装、锁定或切选不会把待机轨道反复重置到起点。减少动态效果设置继续覆盖全部新增动画。

本轮未运行自动测试或浏览器验证，直接刷新HTML可查看与核对。

### 小圆框与动画连续性修正

六个遗器小圆框各增加双段流光与移动光点：外圈小框12秒顺转，内圈小框9秒反转；与槽框呼吸、图标浮动同时运行。点击小圆框有一次短促的扩张与提亮，不暂停流光，空槽同样提供点击反馈。

装备总览改为保留大轨道、小圆框及图标的DOM节点。点击遗器、锁定、更新详情只调整选中状态与相关文字；换装只替换对应槽内图片，大轨道和小圆框的转动持续运行。属性汇总的展开状态也保留。离开装备页再返回时用时间相位衔接；页面刷新仍是重新启动演示。

## 后续顺序

### 16:9 宽屏布局修订（2026-10-11）

本节取代此前将库存堆在六槽下方的布局。采用1440×810固定参考画布，整个画布只使用一个缩放系数；浏览器比例不一致时保留余白，不独立拉伸横纵轴，也不通过手机断点重排六槽。

- 左侧136像素功能导航，中间装备/养成工作区及库存并列，右侧268像素详情。四种材料位于中间区域顶部。
- 装备图占独立416×416正方形；外圈轨道保持正圆，四角槽108×108，内圈轨道210×210，中央斜对角双槽82×82。外圈四角及内圈左上/右下的顺序不变。
- 库存独立占据整列并滚动，不占用装备图下方空间。名称搜索始终显示，其他筛选和排序默认折叠；展开筛选时仅减小库存的可滚动高度。
- 套装摘要和贡献汇总仍在六槽下方；展开贡献时只滚动装备工作区，不改变圆的尺寸。详情独立滚动，底部装备操作固定可见。
- 待机轨道、小圆框及图标节点仍保留；点击遗器和切换筛选不重置待机计时。改版没有更改预览成长、套装效果或材料消耗。

新增`遗器宽屏布局.css`作为布局覆盖，原有视觉与动效样式保留。刷新原HTML即可查看。此次未运行浏览器自动测试或启动游戏。

后续修订：库存列固定320像素，相比上一版约缩窄两成，释放的宽度留给装备/养成工作区。库存仍为三列，卡片高度146像素，图像、星级、名称、主属性分别占独立行；长文本省略并通过悬停标题查看完整内容，避免文字越过卡片边界。

库存渲染按物品ID复用卡片节点，只有内容变更时才更新卡片内部。切换左侧功能、选择遗器时保留未变化的图片与滚动位置；筛选或排序改变后，仅调整对应节点顺序。库存出现动画仅淡入，点击/选中改用内描边光效，去除卡片整体缩放与亮度滤镜，减少文字和像素图片的短暂模糊。此次同样未运行自动测试或客户端。

游戏中的椭圆来自原生UI为容纳底部库存而使用了不同的横纵半径，不是共享屏幕等比缩放造成的。后续按本宽屏版重新实现：先留出正方形装备区，再排库存及详情，轨道必须使用单一半径；页面空间不足时等比缩放或滚动，不压扁装备区。当前游戏代码尚未按本版修改，待用户核对HTML后接入。

按用户本次调整：**HTML界面与交互定稿 → 游戏内UI框架 → 遗器系统与数据接入 → 联合验收**。

游戏内UI先实现布局、控件、详情/比较、空状态及数据展示接口；真实遗器尚未实现时不把演示库存当成实际装备，不扣玩家材料或提供虚假的培养结果。后续再接物品与六槽、服务器校验、属性/套装、强化/分解/合成/重掷和决斗场。套装与数值可以在界面阶段继续核对，不阻塞基础UI设计。
