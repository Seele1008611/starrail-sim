# 1.8.0 九命途网格特效设计室

打开本目录的 战斗特效设计图.html 即可预览。使用本地 HTML、CSS、Canvas 与现有命途图标，不需要联网或新增依赖。

当前版本重新设计为自定义几何网格原型：连续光带、盾片、叶瓣、符文、晶体、彩带与几何碎片。Canvas 是游戏网格的形状和动画设计参考，不是 Minecraft 渲染管线的验证。

## 文件

- 战斗特效设计图.html：选择命途、技能及预览方式。
- 命途特效配置.js：九命途颜色、24 种技能条件，以及韧性削减和击破。
- 战斗网格.js：局部坐标、光带面片、几何模型、分段动画及主体对齐。
- 战斗特效.css：沿用项目界面样式与响应布局。

旧粒子脚本、粒子图案和旧静态预览已删除，不再作为当前设计使用。

## 预览操作

1. 选择九命途中的任意一个及具体效果；选择近战或远程。自身增益不播放攻击箭迹。
2. 时间轴可拖动；可暂停、慢放或循环。
3. 选择斜侧、正面或侧面视角，以及标准/近/远距离。
4. 开启“显示对齐基准”，对照玩家中心、目标中心、特效锚点和脚下方向线。
5. 开启“目标受击移动”，比较“跟随主体”与“命中位置固定”。默认跟随主体，特效中心与目标中心重合；固定模式用于展示受击移动之后的世界位置残留。
6. 查看多目标与触发技同时击破。多目标机制光带只连接设计中的实际受影响目标，场景增加目标不会自行增加机制命中。
7. 完整/简化精度控制光带分段数，页面计数为网格面片而不是粒子数。

## 游戏接入的坐标约定

- 坐标统一为世界坐标；局部网格点 = 主体锚点 + 局部偏移。
- 增益绑定玩家中心；命中壳层、标记和随身轮廓绑定实际目标中心；地面层单独使用该主体脚下高度。
- 目标移动后可继续跟随的效果需要服务端提供目标实体 ID，客户端计算当前插值中心。无法找到实体时，可保留原命中位置短暂消散，不能自动改用玩家或其他敌人。
- 到达弹道和瞬时命中轨迹使用服务端确认的攻击方向与命中位置，不补发箭或重新计算伤害。
- 相机平移只处理一次，世界坐标减相机坐标之后再套视图旋转；检查渲染阶段提供的矩阵，防止重复旋转/平移造成整组特效偏离主体。
- 第一步先画世界坐标锚点与目标包围盒，在目标中心重合后再接刀光、翼芒和汇聚矢。第二步检验脚下层，最后加入装饰。
- 透明排序、墙体遮挡、第一/第三人称和华丽画质均需要游戏实机验收，HTML 不能代替这些检查。
