# 1.6.0 九命途行迹 HTML 样机

- `巡猎行迹设计图.html`：九条命途的树形与交互预览；文件名保留巡猎先行阶段的名称。
- `巡猎行迹.css`、`巡猎行迹.js`：本样机专属样式与演示交互，不修改 1.4.0 UI 模板。
- 图标引用项目内对应的 `崩铁/命途/[命途名]命途.png`，材料图标引用模组内九种像素纹理；星空背景由 CSS 绘制。公开仓库不需要原作参考素材目录即可打开样机。

本页中的节点点亮与重置仅为网页交互演示，不修改游戏存档或真实物品。九条命途的材料名称、节点成本与游戏 1.6.0 规则一致：属性节点按开放等级消耗，被动节点依次消耗 3、4、5 个；每棵树全解锁共消耗 33 个对应材料。

节点选中会产生聚焦光环，点亮时节点与行迹连线同步脉冲；回退时已点亮节点从分支末端依次淡出。分支线上有持续流动的高亮光迹，底部汇合处不添加圆形装饰。支持系统的“减少动态效果”偏好设置。

分支线条按用户提供的九张参考图逐段描绘，对应顺序为欢愉、虚无、同谐、智识、毁灭、记忆、巡猎、丰饶、存护。各命途使用参考图自身的画布坐标，保留开放弧线与独立折枝；原有六个属性节点和三个被动节点映射到参考位置。SVG 与交互节点使用同一等比缩放和居中偏移，窗口变化时同步重新定位。
