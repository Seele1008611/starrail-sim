## 1.9.0 玩家状态栏设计

1.4.0 游戏内 UI 已按本地 HTML 参考稿完成，并通过玩家手动验收。原作 UI 模板、分辨率适配稿、截图和从用户提供视频提取的参考图片保留在本地工作区；这些参考文件不随公开源码仓库分发。
