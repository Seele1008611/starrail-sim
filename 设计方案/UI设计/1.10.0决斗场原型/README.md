# 1.10.0 遗器试炼决斗场原型

入口：[决斗场设计图.html](决斗场设计图.html)。直接用浏览器打开，不需要安装依赖或启动服务。

## 原型展示

- 可按方块实际搭建的 Minecraft 风格场地：25×25格占地、2格厚围墙、21×21格室内净空；墙高7格、四角3×3塔楼高9格、顶部开放。
- 建筑透视与俯视布局可切换。俯视图按方块网格画出北侧5格宽入口、四角塔楼、阶梯式环形地面纹样、中央3×3台座和四向召唤点。
- 材料参考只用原版方块：石砖、深板岩砖、磨制安山岩、暗海晶石、海晶灯、末地烛、磁石（中央装置的原版示意核心）和5扇深色橡木栅栏门；标出由地坪、墙体、门、塔楼到照明的施工顺序。
- “逐块建造”按Y高度逐层显示25×25网格；每个实心格对应一个方块坐标。点击单格可标记已放置/撤回，也可标记整层完成。
- 材料数量由同一份逐块坐标表生成，实时显示总需求、已放置和剩余量；施工标记保存在当前浏览器本地，可手动重置，不会写入游戏存档。
- 五套已确定的遗器套装可选，复用项目已有原尺寸像素风格图标。
- 选择命途等级后，展示对应的三波敌人组合、精英属性倍率和遗器星级概率。
- 展示整合包兼容生物池筛选流程：从已加载的普通敌对生物候选开始，再排除BOSS/高危实体、检查安全生成条件，最后分成近战与远程池；特殊实体仍可由整合包名单配置。
- 每波固定4只，共3波。点击场内敌人可逐只模拟击败；也可用“清完本波”快速查看后续波次。
- 开场时模拟锁定难度与星级；完成最后一波后展示一件所选套装的随机部位。重新挑战会重新开启场次。
- 响应式适配桌面和较窄窗口，轨道和场地保持比例，不拉伸成椭圆。

## 设计边界

HTML本身是纯前端设计稿，不读取Minecraft存档，也不控制服务端掉落。游戏内另有管理员命令 `/starrail arena build`，按此坐标方案在玩家南侧生成25×25场地；命令只在连续坚实地面、全区域无阻挡且区块已加载时施工，不挖地形或覆盖既有建筑，建造中断会回滚本次放置。管理员站在平坦场地北侧入口外执行命令，完成后从北门进入并使用中央遗器试炼台。HTML中的敌人点击、随机星级和部位仍只用于演示流程。等级分布、精英倍率和模组实体筛选规则仍待一次性实机验收；远程敌人的投射物伤害倍率也需检查。
