# 玩家状态栏原型

打开 [玩家状态栏设计图.html](玩家状态栏设计图.html) 即可预览，无需服务器、联网或安装依赖。

## 可以操作什么

- 状态栏仅显示玩家当前状态，不显示命途名称、图标或技能。
- 切换初期、后期、百万生命值预设，完整数值或K/M简写。
- 模拟受伤、治疗、获得伤害吸收、进食，或启用战斗循环。
- 切换水下、骑乘、创造、旁观和F1隐藏；回退原版状态栏布局示意。
- 比较16:9、4:3、21:9画面；默认经验条上方，也可放左下角，缩放75%～100%。
- 状态栏高度28px，两行浮动读数，移除整块背景和边框；宽度不超过主快捷栏，左侧副手槽用独立格示意。水下/骑乘状态不增加高度。

生命与吸收生命读数独立；吸收条相对最大生命值画比例，不表示最大护盾。护甲和韧性显示数值。饱和度在饥饿条下沿以浅绿细线补充，两者绘制参考均为20；饱和度当前上限仍为实际饱食度。吸收生命为零时隐藏相应读数与细线。

原型世界背景使用本地Canvas绘制几何回廊，不是游戏截图。状态为设计示例，成长预设不代表游戏最终面板。

## 文件

- 玩家状态栏设计图.html：页面与状态栏结构。
- 玩家状态栏.css：布局、配色、状态动画和画面适配。

布局细化：护甲和护甲韧性位于饱食度条下方；生命条下方仅显示吸收生命及氧气/坐骑状态。点击“低血预览”可查看生命≤25%及低饱食度提示；受击、护盾、治疗、进食分别在对应部位反馈，布局保持28px高。

护盾按钮已修复图标与按钮同名ID造成的事件绑定冲突。点击后增加真实预览状态中的伤害吸收值（每次为最大生命值的20%），显示蓝色吸收条与“+数值”；受击优先扣除吸收值，剩余伤害才扣生命值，不将吸收值计入最大生命值。此比例仅为原型操作示例，游戏中仍按各能力护盾额度结算。

骑乘跳跃蓄力进一步压缩为2px高、主快捷栏宽度28%（最多84px）的短条，利用经验条上方左侧既有间隙，不增加快捷栏容器高度，不顶高玩家状态栏；取消整行文字，保留悬停说明和无障碍读数。

整体收尾细化：统一数字和图标对齐、细条轮廓及空条端点；低氧气（≤60/300）和低坐骑生命（≤25%）增加暖色提示。骑乘时出现“蓄力跳跃”按钮，短条从0充至100%后归零，默认不显示虚构的固定56%蓄力。保留两行28px、快捷栏宽度及副手槽边界；游戏版已按原版快捷栏182 GUI单位适配，并读取实际跳跃进度。
