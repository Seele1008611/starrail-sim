# 盔甲贴合模型

`曦铁盔甲贴合模型_外层.bbmodel` 是这次调整的 Blockbench 原型，使用 Minecraft 标准 64×32 盔甲图集 UV，并嵌入曦铁外层贴图作为预览。头盔正面采用透明开口，让穿戴者的脸直接显示。

游戏中由 `PathArmorModels` 使用同一套原版人形部件和 UV 布局：头盔、胸甲、护腿和靴子的外层外扩为 0.35；护腿内层外扩为 0.25。原版盔甲模型会将腿部外扩额外收回 0.1，因此实际腿部外扩分别是 0.25 和 0.15。这样能减少手臂、躯干和腿部显得过宽的情况，同时保留贴图与动作姿势。

四套完整盔甲共用这套几何比例。四套 `layer_1`、`layer_2` 图集都按 Minecraft 原版盔甲 UV 的透明轮廓清理了未覆盖区域；头部正面 UV（x=8–15、y=8–15）会露出玩家脸部，肩甲下方的手臂、腰部与脚踝也会露出对应的玩家模型或下层盔甲。颜色保持原设计，只调整透明度。物品留档图与游戏资源图集保持同步。Blockbench 文件用于检查和后续调整模型原型；游戏运行时的几何定义位于 `src/main/java/com/starrail/sim/client/PathArmorModels.java`。
