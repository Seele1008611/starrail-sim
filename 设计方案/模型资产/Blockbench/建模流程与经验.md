# Blockbench 生物与实体建模流程

本文记录项目中可重复使用的建模方法，适用于原创动物、怪物与其他方体角色。目标是减少中间产物，优先让模型比例贴近已确认的设计。

## 工作顺序

### 1. 先画简化建模三视图

- 先确定生物的用途、体型参照、轮廓特征和需要表达的部位，再画正面、侧面、背面三视图。
- 三个视图使用相同的整体高度和地面基线，头、躯干、四肢和尾部的位置彼此一致。
- 三视图是建模参考，不是精细概念插画：优先画清大体块、比例、轮廓和连接关系；暂不画复杂纹理、光效、装饰或动作姿势。
- 眼睛、鼻子、嘴等五官通常留给贴图表现，不为它们增加多余几何体，除非设计明确要求凸起结构。
- 先检查三视图之间是否互相矛盾，再进入 Blockbench。比例不对时先改三视图，避免在模型里凭感觉补设定。

### 2. 直接在 Blockbench 按三视图搭建

- 默认跳过 HTML 三维蓝图，直接以三视图为依据建立 Blockbench 方体比例稿。只有用户明确要求时才增加 HTML 或其他中间稿。
- 以有棱角的立方体、长方体为默认几何语言，先搭核心躯干、头颈、四肢和主要附属结构；不为了细节过早增加小方块。
- 按可辨认或后续需要活动的部位分组，给活动部位设置合理枢轴；左右对称部件可复用尺寸，但仍需检查视图中的实际位置。
- 关键连接处采用适度重叠，避免方块只在边缘相接后留下细缝。完成躯干、头颈、肩臂、腿脚连接后，分别检查正面、侧面和背面。
- 不添加三视图未表达的装饰。若模型整体比例或结构方向错了，先清除错误几何并从三视图重搭，不要在错误基础上不断叠补丁。
- 建模前另列动作清单：每种新生物至少有一个与物种行为关联的专属动作；怪物的各个招式要有各自的前摇、攻击和收势表现。三视图保持中立姿态，动作姿势单独规划，避免把动态动作挤进比例参考图。

### 3. 几何确认后再完善贴图

- 先让用户检查比例稿；主要体块和连接关系确认后，再绘制像素风贴图。
- 贴图保持 Minecraft 的低分辨率像素质感，控制颜色数量和明暗层次。石材、金属、晶体等材质各用清晰但克制的色块区分。
- 贴图制作后检查 UV：正面、侧面、背面和小部件都要落在预期区域；重开模型再确认 UV 与贴图没有错位。
- 五官、表面花纹和材质变化优先由贴图表现，避免为了贴图细节把几何做得过碎。

### 4. 保存、归档与审阅

- Blockbench 文件放进 `设计方案/模型资产/Blockbench/` 下已有的用途分类，不按版本重复建素材文件夹。
- 生物与实体贴图原稿放在 `崩铁/物品/生物与实体/`；方块、食物、装备等按素材性质归档。运行时资源另按 Minecraft 资源目录规范存放。
- 保存后确认目标 `.bbmodel` 存在且包含最新几何、分组和嵌入贴图；有外置贴图原稿时也逐一确认文件可打开。
- 修改已通过的模型时保留原稿。若需要彻底重建，另存为新的对照稿，避免覆盖已验收版本。
- 交付时说明模型处于三视图、比例稿、贴图稿还是运行时接入阶段；未经用户审阅，不把比例稿称作最终游戏模型。

## 本项目实践要点

- 星砾驮兽等动物建模中，细节过多的参考图容易诱导模型反复堆叠方块；先分离“建模三视图”和“细节说明”，让比例先稳定。
- 纯方体三视图足以作为 Blockbench 直接建模依据；本次星脉构装守卫跳过 HTML 后，完成了可审阅的体块模型和贴图。
- 胸口框架的四段需要在正面接成连续轮廓；从侧面看时，框、中心晶体、后托和躯干要有实际重叠，避免看起来像互相悬空。
- 原创动物不能只换模型和贴图：要为各物种安排能对应觅食、移动或互动的独有动作；Boss 的不同招式也需要独立动作阶段和清楚提示。
- 当前通过的模型和原稿优先保留。新方法先作为默认流程使用，具体比例与装饰仍以用户给出的设计为准。
