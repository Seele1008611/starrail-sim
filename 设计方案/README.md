# 设计方案与项目文档

本目录集中保存项目规则、版本计划和遗迹设计资料。根目录的 `README.md`、`CHANGELOG.md` 与 `releases/` 仍作为 GitHub 项目说明、更新日志和逐版发布归档。

## 分类

- [项目文档](项目文档/README.md)：设计总纲、命途与战斗机制、版本计划。
- [遗迹设计](遗迹设计/README.md)：概念设计板、模型源文件、预览图和验收记录。
