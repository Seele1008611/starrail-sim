# 崩铁小模拟 1.27.0 正式发行

适用于 Minecraft 1.20.1、Forge 47.x 和 Java 17，构建使用 Forge 47.4.10。需要 Curios API 5.14.1 或兼容更新版。JEI 和 Lootr 为可选模组。

## 本版内容

- 重做命途技能与战斗特效、五种动物及虚卒和构装守卫的模型动作，追加末日兽首领、战斗场地及掉落兑换。
- 扩充命途遗境群系、生态、食物和料理，接入料理台 JEI 展示，并补全行旅档案区域文案。
- 在命途遗境新增四座探索建筑和 27 件奇物。三个奇物栏位，建筑宝箱与补给桶共享随机池，包含连续开箱保底。
- 调整巡猎光锥与协奏领域，支持满饱食度继续进食。
- 兼容 Lootr 个人战利品容器。每位玩家首次打开合格箱子或补给桶时独立结算奇物，并支持遗迹档案与进度登记。
