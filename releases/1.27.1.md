# 崩铁小模拟 1.27.1 正式发行

2026-11-15。适用于 Minecraft 1.20.1、Forge 47.x 和 Java 17。需要 Forge 版 Curios API，构建使用 5.14.1+1.20.1。

## 本版内容

- 更新 136 张物品图标。30 道料理参考米游社图鉴还原造型与配色，其余为食材、预制料、厨具、种苗和植物等图标。
- 荷洲荷叶及 10 个植物改用独立的物品模型贴图，保留放置外观。
- 用户确认 test87 实机通过。正式包经 Java 17、Gradle 8.8 离线构建和重混淆，与 test87 逐条比对，仅版本元数据有差异。网络协议保持 26。
