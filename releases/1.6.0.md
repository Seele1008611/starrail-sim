## 本版内容

- 九条命途各自拥有六个属性节点与三个被动节点；行迹进度按命途独立保存，切换后只启用当前命途效果。
- 九种行迹树拥有独立分支布局和完整的命途背景图标，布局依据用户确认的命途图标与分支参考图制作。
- 九种像素风命途材料加入游戏，并提供中文和英文说明。
- 行迹节点升级由服务端检查命途、等级、前置关系和材料；支持单节点连带回退以及全部重置并返还材料。
- 新增权限等级 2 的行迹测试命令：`/starrail path debug set <path>`、`prepare <path>` 和 `clear`。原有正常踏上命途流程不变。
- 玩家基础护甲值为 2、基础护甲韧性为 1。
