## 1.25.0 内容

- 命途遗境七个既有群系加入虚卒·掠夺者、虚卒·篡改者、虚卒·践踏者和虚卒·抹消者；四者承担不同战斗职责。
- 遗器试炼波次改由四种新增虚卒组成，并保留既有波次数量、设备归属和构装守卫 Boss 流程。
- 加入虚质残片、虚质重甲片、虚质裂刃配方及四种虚卒的静态指南条目。
- 四种虚卒使用用户确认听感通过的 Freesound CC0 音效资源；具体素材与处理记录随模组许可证资源归档。

## 构建与包检查

- 环境：Temurin Java 17.0.20+8、Gradle 8.8；使用现有缓存并离线构建。
- 命令：`gradle.bat --offline --console=plain '-Dnet.minecraftforge.gradle.check.certs=false' '-Pmod_version=1.25.0' reobfJar`。
- 结果：`BUILD SUCCESSFUL`，退出码 0；`compileJava` 为 `UP-TO-DATE`，`processResources`、`jar` 和 `reobfJar` 成功。Gradle 报告已有弃用 API 警告。
- JAR 元数据：`META-INF/mods.toml` 版本为 `1.25.0`；manifest `Implementation-Version` 为 `1.25.0`。
- 测试包比较：与 `build/libs/starrail_sim-1.25.0-test.jar` 比较，排除预期变化的 `META-INF/mods.toml` 和 `META-INF/MANIFEST.MF` 后，2,313 个条目的 SHA-256 全部一致，缺项和内容差异均为 0。两包各有 2,315 个文件条目。
- 发行包包括四种虚卒实体、虚质裂刃与材料、指南、双语文本及声音资源。关键类、`sounds.json`、许可证文件和中文语言资源均存在。
- 构建前后用户级 Gradle 模块缓存均为 135 个文件、ForgeGradle 缓存均为 4,173 个文件；工作区 Gradle 模块缓存为 9 个文件、ForgeGradle 缓存为 301 个文件，计数均无变化。构建命令为 `--offline`；无依赖下载。为避免向只读用户缓存写 native lock，本次将 Gradle 用户目录指向工作区已有 `.gradle`，并用用户级缓存作为只读依赖缓存。
- 本轮未运行自动化测试或启动游戏；阶段5测试由用户报告全部完成且没有失败项，但逐项结果、具体环境和数值未传达。本记录不据此推断多人或专用服务端的具体覆盖范围。
