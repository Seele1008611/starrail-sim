## 本版内容

- 重做角色详情、属性详情、光锥、命途与命途指南五个客户端页面，对齐已冻结的 HTML 参考稿。
- 加入共用星空与星云漂移、地台效果、光锥厚度/反光/七彩底光、命途图形、分区指南、按钮反馈和平滑滚动。
- 属性详情显示基础值、加成和最终值；统一画布、文本宽度适配和内容面板上限支持不同窗口比例与 GUI 缩放。
- 不更改服务器端试炼、寻迹凭证、奖励、命途晋阶和光锥叠影规则。改版前客户端 UI 与语言文件备份继续保留。

## 环境与验证

- Minecraft 1.20.1；发行元数据要求 Forge `[47,)`、Curios `[5.14.1,)`。
- 玩家于 2026-10-06 确认最终 UI 动效、不同窗口比例、GUI 缩放及既有交互手动验收通过。
- Java 17、Gradle 8.8，使用现有缓存离线运行 `reobfJar` 成功；JAR 中版本为 `1.4.0`，Minecraft 范围 `[1.20.1,1.21)`，Forge 范围 `[47,)`，Curios 范围 `[5.14.1,)`。资源和新增客户端类已核对。
- 本版仅包含客户端 UI，未改服务端规则；未另做专用服务器验收。多人连接和跨 Minecraft 基础版本存档迁移未验收。
- 自动化测试任务未运行；项目现有手动验收结果由玩家确认。
